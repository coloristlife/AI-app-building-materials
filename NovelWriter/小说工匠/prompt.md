# 将你的提示词整理到子菜单中

## **将你的提示词整理到子菜单中（Organize Your Prompts into Submenus）**

### **如何使用新的虚拟文件夹功能，在小说工坊（Novelcrafter）中整理你的提示词**

阅读时间：1 分钟
最后更新：2026 年 2 月 8 日

---

## **创建新的子菜单（Creating a New Sub-menu）**

要将你的提示词（Prompts）整理到不同的子菜单中，你首先需要进入：

**提示词界面（Prompt Interface）**

然后，在某个提示词的**名称（Name）**字段中：

1. 输入用于存放该提示词的**文件夹名称（Folder Name）**
2. 在文件夹名称后输入：

   * 一个空格
   * 正斜杠 `/`
   * 一个空格
3. 输入你的**提示词名称（Prompt Name）**

格式如下：

```
文件夹名称 / 提示词名称
```

例如：

```
角色设计 / 创建角色背景
```

或者：

```
剧情开发 / 三幕结构分析
```

保存后，小说工坊会自动创建对应的**虚拟文件夹（Virtual Folder）**，并将该提示词归类到相应的子菜单中。

---

这个功能适合用于管理大型 AI 写作项目，例如：

* **角色设计**

  * 创建角色背景
  * 分析人物动机
  * 角色弧光设计

* **剧情开发**

  * 三幕结构分析
  * 节拍设计
  * 冲突升级

* **世界观构建**

  * 地理设定
  * 历史背景
  * 社会规则

可以把小说工坊中的大量提示词整理成类似“AI 小说创作知识库”的结构。
