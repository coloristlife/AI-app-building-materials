> **什么是 Codex 分类，如何在项目中使用它们？**

自定义分类（Custom categories）是一种将相关的 Codex 条目分组管理的方法——例如，你可能有一个黑帮组织，你想把该组织的所有成员、他们的藏身处、相关背景故事（Lore）、以及他们拥有的任何重要武器或物品全部归类到一起。

通过这种分组，你可以更容易地找到你的条目；而且，如果你正在编写压根用不上这些设定的场景，你还可以将整个分类折叠收起。

---

## 如何创建一个自定义分类？

要创建一个自定义 Codex 分类：

1. 在 Codex 侧边栏中，点击**齿轮图标（cog icon）**。
    
2. 选择 **Custom Categories（自定义分类）**。
![[Snapzy_2026-08-13_21-14-30_773 1.png]]
    
3. 点击 **+ New（+ 新建）**。
![[Pasted image 20260813211456.png]]
    
4. 为你的分类命名，选择一个颜色（可选），选择关联的类型（如果不确定，保留全选即可），并选择关联的标签（Tags）。这将决定你需要为条目指定什么“标签”，从而把它归入该分类。命名完成后，你的 Codex 分类就会显示在侧边栏中。 
![[Snapzy_2026-08-13_21-16-50_748.png]]
> 自定义分类可以在同一个系列（Series）的不同作品之间共享，但不能跨越不相关的独立书籍。  
> 你可以通过点击 Codex 中分类旁边的**铅笔图标**来编辑自定义分类。

![[Snapzy_2026-08-13_21-18-48_125 1.png]]

## 颜色编码分类（Colour-coded categories）

每个自定义分类都可以被指派一种颜色，该颜色会显示在 Codex 侧边栏的分类名称旁边，方便你一眼就能在视觉上区分不同的分类。

- 要设置或更改颜色，请打开分类编辑器，并选择右侧“Color（颜色）”区域中的色块之一。点击带有斜线的圆圈图标即可清除颜色。
    

---

## 处于多个分类中的条目

一个条目可以**同时**出现在多个自定义分类中。当某个条目符合多个分类的规则时——例如因为它带有多个标签，且每个标签分别关联了不同的分类——它会同时被列在所有这些分类下面。

这使得从不同角度查看相关条目变得轻而易举。例如，一个既是某个公会成员又是某城市居民的角色，会同时出现在“公会”和“城市”两个分类中。

> ℹ️ **提示：**  
> 当一个条目属于多个分类时，其颜色由列表中**最上方**的那个匹配分类决定。你随时可以通过直接在条目本身上设置颜色来覆盖这个默认颜色。

## 如何将条目移入自定义分类？

### 方法 1：通过标签（By Tags）

将 Codex 条目转移到自定义分类中：

1. 点击打开该 Codex 条目。
    
2. 在标签（Tag）区域，输入你为该分类指定的“标签”。例如：“Rivers”（里弗斯家族）。
    
3. 此时，该项目将出现在“Rivers Family”分类中，而不是原本的 Codex 角色分区里：
    

**如何从自定义分类中移除条目？**  
只需在标签/标签栏中删掉对应的关联标签即可。

### 方法 2：通过 Codex 细节（By Codex Detail）

1. 前往 **Codex Categories** 并选择你的分类。
    
2. 点击 **+ Add Detail（+ 添加细节）**。
    
3. 选择你关联的 Codex 细节（仅限下拉菜单类型）以及对应的子分类。
    
4. 现在，任何带有该 Codex 细节的 Codex 条目都会自动被添加进这个 Codex 分类中。

## 如何删除一个自定义 Codex 分类？

> ℹ️ **提示：**  
> 删除自定义 Codex 分类**只会删除分类本身**——原有的 Codex 条目都会被保留。

要删除自定义 Codex 分类：

1. 在 Codex 侧边栏中，点击**齿轮图标**。
    
2. 选择 **Custom Categories**。
    
3. 选择你想要删除的自定义分类。
    
4. 点击 **Delete Category（删除分类）**。

## 核心概念与技术解释

1. **多对多动态视图（Many-to-Many Dynamic Views / Tag-based Tagging）**
    
    - **技术本质**：与传统文件夹（Folder）式的“单一归属”不同，Novelcrafter 的自定义分类本质上是一个**基于标签与属性的动态过滤视图（Dynamic Filter View）**。条目和分类之间是多对多（Many-to-Many）关系。条目本身不改变物理存储路径，分类只是根据设定好的规则（Tags 或 Codex Details）动态“抓取”符合条件的条目进行展示。
        
2. **表现层与元数据的解耦（Decoupling of Presentation and Metadata）**
    
    - 通过支持“一个条目出现在多个分类中”以及“颜色覆盖逻辑”，系统成功实现了视觉组织（UI Organization）与底层世界观数据（Worldbuilding Data）的解耦。作者可以完全为了写作时的视觉检索便利去任意组合分类，而不会破坏 Codex 底层实体的唯一性和完整性。
