
**什么是 Series Codex（系列设定库）？它与 Book Codex（单本书设定库）有什么区别？**


**Series Codex（系列设定库）** 与普通的 **Codex（设定库）** 功能基本相同，不同之处在于：

**其中的所有设定条目都会在整个系列（Series）的所有书籍之间共享。**

也就是说，你只需要创建一次设定，就可以在该系列的每一本书中直接使用，而无需为每本书重复创建相同的内容。

例如，如果你正在创作一个三部曲：

* 《第一部：觉醒》
* 《第二部：裂变》
* 《第三部：归来》

那么下面这些适合放入 **Series Codex**：

* 世界观设定
* 国家与地图
* 历史背景
* 神话体系
* 科技设定
* 长期存在的角色
* 组织、势力
* 魔法（或规则）体系

这些内容在三部作品中都是共享的，因此只需维护一份。

而每一本书各自独有的内容，则更适合放在 **Book Codex（单本书设定库）** 中，例如：

* 本书新增的人物
* 本书特有的事件
* 本书出现的新地点
* 当前章节才会涉及的线索
* 本书专属的剧情设定


### Series Codex 与 Book Codex 的区别

| **Series Codex（系列设定库）** | **Book Codex（单本书设定库）** |
| ----------------------- | ---------------------- |
| 整个系列共享                  | 仅当前这一本书使用              |
| 创建一次，所有书可引用             | 每本书独立维护                |
| 适合长期稳定的设定               | 适合当前作品专属设定             |
| 修改后会同步影响整个系列            | 修改只影响当前书               |

### 一句话理解

可以把它们理解为：

* **Series Codex = 系列级设定库（所有作品共享）**
* **Book Codex = 单书级设定库（仅当前作品使用）**

这种设计既避免了重复维护相同设定，也能让整个系列保持一致性，同时保留每一本书独有的内容。
