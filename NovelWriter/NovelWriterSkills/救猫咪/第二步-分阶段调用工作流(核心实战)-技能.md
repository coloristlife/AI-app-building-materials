
### 第二步：分阶段调用工作流（核心实战）

引擎加载后，你就可以按照“设定 ➡️ 大纲 ➡️ 场景 ➡️ 结尾”的顺序，精准调用特定的 Module 和 Skill。

#### 阶段 1：塑造人物（调用 模块二 / Skill 5）
故事开始前，先做人物小传。此时只需让 AI 专注在人物内核上。
*   **你的 Prompt：**
    > “我要写一个赛博朋克背景下的赏金猎人。请调用 **Skill 5 (认知失调塑造器)**，帮我设定他身上的 The Lie（谎言）、Want（伪目标）和 Need（灵魂需求）。并为他的出场设计一个‘救猫咪’的瞬间，锁定读者的共情。”

#### 阶段 2：规划剧情大纲（调用 模块一 / Skill 1、3、4）
有了人物，开始排兵布阵。
*   **你的 Prompt：**
    > “现在我们来规划第一幕的剧情结构。
    > 1. 请调用 **Skill 1 (预测误差)**，设计一个反套路的‘激励事件’。
    > 2. 调用 **Skill 4 (信息差)**，在这一幕埋下3个不起眼的伏笔。
    > 3. 确保剧情走向符合‘因为...所以...但是’的因果逻辑（遵守禁忌2）。”

#### 阶段 3：撰写具体正文（调用 模块三 / Skill 6）
这是最容易写出“AI味”的环节。此时你必须用微观法则死死按住 AI，不让它放飞自我。
*   **你的 Prompt：**
    > “现在我们要写主角潜入反派大楼的场景。请**严格执行 Skill 6 (微观法则)** 进行正文撰写：
    > 1. 剧情必须由主角的欲望驱动（他要找到钥匙）。
    > 2. 行文严格遵守‘Show, Don't Tell’，禁止出现‘他很紧张’这种词，用生理反应描写。
    > 3. 遭遇突发状况时，绝对遵守 MRU 顺序（客观刺激 ➡️ 生理 ➡️ 下意识动作 ➡️ 理性）。
    > 4. 遵守禁忌3，不要让他轻易得手，给他制造一个灾难。”

#### 阶段 4：收尾与制造悬念（调用 模块一 / Skill 2）
一章写完了，你需要留住读者。
*   **你的 Prompt：**
    > “当前章节正文已经完成，现在请调用 **Skill 2 (蔡格尼克钩子)** 帮我写最后 300 字的结尾。制造一个意想不到的突发事件挂起悬念，并通过‘延迟满足’打断当前动作，让读者急于看下一章。”

Here is the English translation, maintaining the original Markdown formatting:

**Stage 1: Shaping the Character (Invoke Module 2 / Skill 5)**  
Before the story begins, let's create a character biography. At this point, simply have the AI focus on the character's core.

Your Prompt:
"I want to write about a bounty hunter in a cyberpunk setting. Please invoke Skill 5 (Cognitive Dissonance Shaper) to help me set up his The Lie, Want (False Objective), and Need (Soul's Requirement). Also, design a 'Save the Cat' moment for his introduction to secure the reader's empathy."

**Stage 2: Plot Outline Planning (Invoke Module 1 / Skills 1, 3, 4)**
With the character established, it's time to map out the plot.

Your Prompt:
"Now let's plan the plot structure for Act 1.

Please invoke Skill 1 (Prediction Error) to design an unconventional 'Inciting Incident'.
Invoke Skill 4 (Information Gap) to plant 3 inconspicuous setups in this act.
Ensure the plot progression aligns with the 'Because... Therefore... But' causal logic (abide by Taboo 2)."

**Stage 3: Drafting the Specific Text (Invoke Module 3 / Skill 6)**
This is the stage most prone to an "AI-generated vibe." At this point, you must firmly restrain the AI using micro-level principles, preventing it from going off the rails.

Your Prompt:
"Now we are going to write the scene where the protagonist infiltrates the villain's building. Please strictly execute Skill 6 (Micro-Level Rules) to draft the text:

* The plot must be driven by the protagonist's desire (he wants to find the key).
* The writing must strictly adhere to 'Show, Don't Tell'. Words like 'he was nervous' are forbidden; describe using physiological reactions.
* When encountering unexpected situations, absolutely follow the MRU sequence (Objective Stimulus ➡️ Physiological ➡️ Reflexive Action ➡️ Rational).
* Abide by Taboo 3: Do not let him succeed easily, create a disaster for him."

**Stage 4: Wrapping Up and Creating Suspense (Invoke Module 1 / Skill 2)**
The chapter is finished, and you need to retain the reader.

Your Prompt:
"The main text of the current chapter is complete. Now, please invoke Skill 2 (Zeigarnik Hook) to help me write the final 300 words of the ending. Create an unexpected sudden event to leave the suspense hanging, and use 'delayed gratification' to interrupt the current action, leaving the reader desperate to read the next chapter."
