针对你最核心的疑问：“需要每个 skill 都使用吗？”
**工程总监的直接回答是：绝对不需要！如果你一次性加载 65 个 Skill，大模型会因为“认知超载（Context Overload）”而彻底精神分裂。**

这套系统的本质不是一张“必须全部打勾的任务清单”，而是一个**“顶级好莱坞电影制作班底的武器库（Arsenal）”**。你作为总导演，要做的是**“对症下药”**和**“按需挂载”**。

# 📖 Novel-OS 系统操作手册 (V1.0)

## 第一章：系统调度的三大铁律

### 铁律 1：严禁“跨界执法”（时序隔离法则）
绝不能把 `editorial_skills`（查逻辑）和 `writing_skills`（写正文）混在一个 Prompt 里发给 AI。
*   **在算大纲时**，让 AI 做个没有感情的数学家（只开 Editorial）。
*   **在写正文时**，让 AI 做个没有理智的疯子，全身心投入动作和五感（只开 Writing）。

### 铁律 2：单次 Prompt 的“3-Skill 甜点上限”
在命令 AI 生成一段 1000 字的正文时，**最多同时挂载 3 个 Writing Skills**。
超过 3 个，大模型就会触发“中间注意力丢失”，顾此失彼。你需要像配药一样，组合出 3 个最切中当前场景的 Skill。

### 铁律 3：不要主动用，要“被动触发”（异常驱动）
很多时候，你只需要给 AI 一个基础指令让它先写。**只有当 AI 写出来的东西出现了某种“病症（AI 味）”时，你才从武器库里抽出对应的 Skill 砸向它，逼它重写。**

## 第二章：`editorial_skills` (制片人质检) 使用指南
**定位：X光扫描仪。** （共 30 个技能，你不需要全用，只需像漏斗一样层层过滤）。

**操作流 (The Funnel Workflow)：**
1.  **定大势（全书大纲期）**：只用 `structure/` (查节拍) + `character/` (查弧光)。
    *   *目的：确保小说大方向不崩盘，主角有成长，有最低谷。*
2.  **定血压（单卷/分集大纲期）**：只用 `tension/` (查压迫感和鸿沟) + `life_texture/` (查生存代价)。
    *   *目的：确保反派在做事，主角在流血，世界有重力。*
3.  **定微操（单章执行大纲期）**：只用 `scene/` (查翻转) + `dialogue/` (查潜台词)。
    *   *目的：确保这一章里的动作不是废戏，台词不是废话。*
*(当大纲通过这 3 层漏斗，Editorial 模块就可以下线了。)*

## 第三章：`writing_skills` (导演渲染) 实战连招表 (Combos)
**定位：特效引擎。** （共 25 个技能）。
这是你日常使用最频繁的模块。不要全开！请根据你要写的**场景类型**，直接套用以下我为你配好的**“技能连招（Combos）”**：

### 🎬 Combo A：【肾上腺素狂飙】（适用于：追车、暗杀、极限逃生）
*   **目标**：写出拳拳到肉的痛感和极快的节奏。
*   **挂载技能 (3个)**：
    1.  `chapter_writer / pacing_controller`（强制 AI 使用短句，压缩时间感）。
    2.  **`scene_writer / mru_sequence_enforcer`（绝对核心！严格执行“外部刺激->生理反应->物理动作”的链条，禁止写情绪词）。**
    3.  `description_writer / environment_as_actor`（让周围的环境活过来，比如写狂风如何撕扯主角的衣服）。
*   *(此时不要挂载 Dialogue，打架时没人长篇大论。)*

### 🎬 Combo B：【高压密室交锋】（适用于：审讯、分手、权谋谈判）
*   **目标**：写出“冰山理论”，字面之下刀光剑影。
*   **挂载技能 (3个)**：
    1.  **`dialogue_writer / oblique_response`（强制 AI 闪避式对答，禁止正面回答“是/否”，大量使用反问）。**
    2.  `dialogue_writer / sorkin_overlap`（强制加入破折号，让角色互相打断，抢夺话语权）。
    3.  `scene_writer / spatial_and_prop`（强制给角色安排一个手部道具，比如一枚硬币，用玩硬币的力度来暗示内心的杀意）。

### 🎬 Combo C：【史诗感过场/情绪沉淀】（适用于：大战之后的废墟、主角的孤独跋涉）
*   **目标**：拉升小说的文学性和电影质感。
*   **挂载技能 (3个)**：
    1.  `description_writer / micro_macro_panning`（强制从一滴血拉远到整个燃烧的城市天际线）。
    2.  **`description_writer / synesthesia_five_senses`（限制视觉描写，逼迫 AI 写出硝烟的嗅觉和冰冷的触觉）。**
    3.  `transition_writer / l_cut_emotional_echo`（将上一场戏的悲伤，用蒙太奇的余韵拖拽进下一场戏）。

## 第四章：AI 写作绝症“急救手册”（Troubleshooting）
作为架构师，当你审阅 AI 生成的正文，觉得“这写的什么狗屎”时，请立刻对照以下症状，服用对应的 Skill 药方：

*   **症状 1：AI 写的正文像剧情大纲，干巴巴的（Summary Syndrome）。**
    *   **一针见血**：立刻调用 **`scene_writer / MRU 法则`**。在 Prompt 里骂它：“禁止概括！把这 50 个字用 MRU 法则放大成 500 字的高精度画面，先写心跳，再写动作！”
*   **症状 2：角色像个没脾气的客服，一问一答（AI Voice）。**
    *   **一针见血**：立刻调用 **`dialogue_writer / 昆汀式闲聊` 或 `非对称交锋`**。命令 AI：“重写对白！A 想要钱，B 偏要聊晚饭的牛排，用牛排的生熟来暗示威胁！”
*   **症状 3：世界感觉像个塑料布景房，毫无真实感（White Room）。**
    *   **一针见血**：立刻调用 **`description_writer / 做旧包浆师`**。命令 AI：“给这间屋子打上包浆！描写生锈的把手、剥落的墙皮和发霉的气味，禁止使用‘干净、崭新’等词。”
*   **症状 4：场景切换极其生硬，“第二天早上”、“随后”（Time Jump Cliche）。**
    *   **一针见血**：立刻调用 **`transition_writer / 匹配剪辑`**。命令 AI：“砍掉‘第二天’！用上一段结尾打碎玻璃的声音，无缝拼接下一段开头切洋葱的声音！”

## 💡 架构师的最终操作建议：如何管理这 65 个技能？

不要试图用大脑记住它们，你要用**系统（IDE / 提示词库）**来管理它们。

1.  **建立“提示词代码片段（Snippets）”库**：
    将我们推演出的每一个 Skill，写成 200 字左右的高效 Prompt 模板。存入你的 Notion、Obsidian，或者输入法的快捷短语中。
2.  **建立标准 Prompt 骨架**：
    你日常发给 AI 的指令应该像一个填空题：
    > **[系统设定]**：你是一个顶级小说家。
    > **[当前大纲]**：XXXX
    > **[挂载技能组]**：*(此处粘贴你今天选中的 1-3 个 Skill 约束代码)*
3.  **像打游戏一样玩转它们**：
    大纲弱，呼叫 `Editorial` 补钙；文笔水，呼叫 `Writing` 雕花；忘了设定，呼叫 `Continuity` 查账。
