### 📂 目录：`editorial_skills/character/` (人物弧光与内核质检)
这个文件夹下的 AI 工具，眼中没有华丽的辞藻，只有**驱动力、缺陷、压力测试和变量**。

#### 🛠️ Skill 1: `want_vs_need_diagnostician` (欲求与需求体检仪)
*   **理论基底**：《故事》（有意识的欲望 vs 无意识的需求）+《救猫咪》（玻璃碎片 Shard of Glass）
*   **核心职责**：检查主角的内在驱动力是否构成冲突，是否有足够的成长空间。
*   **AI 诊断逻辑**：
    1.  **提取 Want（外在欲望）**：主角在第一幕明确想要得到什么？（例如：升职、复仇、找回妻子）。如果 Want 不具体、不可被视觉化，报错。
    2.  **提取 Need（内在需求/玻璃碎片）**：主角在潜意识里真正需要解决的心理创伤或性格缺陷是什么？（例如：学会放下控制欲、学会信任他人）。
    3.  **计算错位感（Misalignment）**：AI 必须核对——主角是否在故事的前半段**误以为**达成 Want 就能治愈 Need？如果 Want 和 Need 是一顺水的（主角一开始就知道自己需要改变什么），报错：“人物缺乏盲区，故事将变得说教”。
*   **输入**：人物小传 / 核心大纲
*   **输出（JSON格式）**：`{"diagnoses": "Want和Need的错位度评估", "shard_of_glass": "识别出的创伤点", "pass_or_fail": boolean, "suggestions": "如何让内在需求埋得更深"}`

#### 🛠️ Skill 2: `empathy_and_flaw_scanner` (共情点与“六个缺陷”扫描器)
*   **理论基底**：《救猫咪》（Save the Cat Moment + Six Things That Need Fixing）
*   **核心职责**：确保主角在展现出让人难以忍受的缺陷时，读者依然愿意跟随他。
*   **AI 诊断逻辑**：
    1.  **寻找“救猫咪”时刻**：在设定的前 10%（铺垫阶段），AI 强制搜索“共情锚点”。主角是否做了一件哪怕微小但展现人性的事？（如：对弱者施以援手、坚持某个底线、处于被极度不公对待的境地）。如果没有，报错：“主角初始仇恨值过高，读者会流失”。
    2.  **盘点“六个亟待修补的缺陷”**：AI 扫描第一幕（正反题世界），列出主角生活中、性格里、人际关系上至少 3-6 个明显糟糕的设定。
    3.  **校验回归点**：AI 对比大纲的结尾，检查这几个在开头被列出的“缺陷”，是否在结尾得到了逐一的修补或推翻。
*   **输入**：第一幕大纲 / 铺垫期事件列表
*   **输出**：`{"empathy_anchor": "提取的救猫咪时刻", "flaws_to_fix": [], "closure_check": "首尾呼应度"}`

#### 🛠️ Skill 3: `pressure_choice_evaluator` (极限施压与真实品格测试仪)
*   **理论基底**：《故事》（人物性格 Characterization vs 真实品格 True Character）
*   **核心职责**：剔除主角身上的“伪善”和“口号”，检查高潮或转折点的选择是否足够痛苦。麦基说：“压力下的选择揭示真实品格”。
*   **AI 诊断逻辑**：
    1.  **区分“表征”与“内核”**：AI 分析主角设定的性格（如：幽默、残忍、怯懦），并检查在危机发生前，这些是否只是表面标签。
    2.  **定位两难选择（Dilemma）**：扫描大纲中的“灵魂黑夜”或“第三幕高潮”。AI 评估主角面临的选择题：
        *   是“两善取其重”（同时想要两个好东西，必须牺牲一个）？
        *   还是“两恶取其轻”（无论选什么都会失去核心利益）？
    3.  **计算压力值**：如果主角在危机时刻，靠着天降神兵、或者做了一个“傻子都知道怎么选”的正确决定度过难关，AI 判定施压失败，报错：“缺乏两难困境，这不是真实品格的显露，这是剧情放水。”
*   **输入**：中点（Midpoint）或 灵魂黑夜（All is Lost）阶段的大纲。
*   **输出**：`{"pressure_level": "1-10分", "dilemma_analysis": "两难拆解", "character_revelation": "压力下揭露了什么真实品格"}`

#### 🛠️ Skill 4: `arc_transformation_calculator` (人物弧光三段论推演机)
*   **理论基底**：《救猫咪》（正题 Thesis -> 反题 Antithesis -> 合题 Synthesis）
*   **核心职责**：宏观俯瞰主角的心理变形记，确保角色没有在中途“停止生长”或“突然顿悟”。
*   **AI 诊断逻辑**：
    1.  **正题（第一幕）**：主角带着旧有缺陷，在旧世界使用旧方法。AI 检查：是否屡屡碰壁但主角依然固执？
    2.  **反题（第二幕）**：主角进入新世界，采用了完全相反的方法（矫枉过正）。AI 检查：主角是否在“游戏时间”里尝到了反向行事的甜头，但核心问题（Need）仍未解决？
    3.  **合题（第三幕）**：主角融合了旧世界的经验与新世界的教训。AI 检查：在大结局的最终对决中，主角使用的方法是否既不是第一幕的，也不是第二幕的，而是 A+B 的升级版？如果没有，报错：“弧光闭环失败，人物没有完成真正的 Synthesis”。
*   **输入**：全书/全剧结构大纲
*   **输出**：`{"thesis": "旧状态", "antithesis": "伪装的新状态", "synthesis": "真理状态", "arc_smoothness": "弧光平滑度评估"}`

#### 🛠️ Skill 5: `foil_network_checker` (对照组与B故事关系网核查仪)
*   **理论基底**：《故事》（对立面原则）+《救猫咪》（B故事角色 / 助推器）
*   **核心职责**：清理无用配角，确保每一个核心配角都是为了逼迫、对照主角的“缺陷”而存在的。
*   **AI 诊断逻辑**：
    1.  **定位 B 故事角色（B-Story Character）**：找到负责跟主角谈恋爱、做导师、做死党的那个人。AI 检查：这个配角是否直接指向主角的“Need（需求）”？配角是否在不断用行动或对话，戳中主角的“玻璃碎片”？
    2.  **盘点对立面（Antagonists & Foils）**：反派或竞争对手是否是主角“如果继续堕落/如果不改变”的极端照镜子？
    3.  **冗余剔除**：如果 AI 发现某个配角的设定仅仅是为了“给主角递道具”或“喊666”，报错：“发现工具人，建议将其戏份合并入 B 故事角色，或赋予其挑战主角世界观的功能。”
*   **输入**：角色关系谱 / 人物小传合集
*   **输出**：`{"b_story_impact": "B角色对主角弧光的干预度", "foils_analysis": "镜像对照分析", "redundant_characters": ["建议删除或合并的工具人名单"]}`

### 💡 总监点评（应用建议）：
在你的工作流中，当你或者 AI 构思出了一份初步的《人物设定表》与《故事大纲》时，**不要急着让 AI 去写正文**。

先调用这 5 个 `editorial_skills/character` 技能，让大模型以 JSON 格式对大纲进行“交叉审讯”。
*   如果 `want_vs_need_diagnostician` 亮红灯，说明你的主角是个纸片人。
*   如果 `pressure_choice_evaluator` 报错，说明你的高潮剧情太水。

**只有当这 5 个工具的跑分全部 Pass，骨骼彻底定型**，你才能把这份经过千锤百炼的“人设数据”和“节拍器”，喂给下游的 `writing_skills/`（场景导演与执笔作家），让它们去调用五感、描写转场、挥洒笔墨。
