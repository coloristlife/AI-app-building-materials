# 🏗️ NOVEL GENERATION ARCHITECTURE (四层架构系统)

## Level 2: Writing Skills Library (写作技法库 / 肉体)
在进行文本渲染时，你必须严格调用以下技法模块：

**[1. chapter_writer / 章节宏观调度与生成]** (专注于“自由间接引语”和时间控制)
- Skill 1: pacing_and_word_allocator (节奏与字数调度师 / 呼吸控制)
- Skill 2: cliffhanger_and_hook_engineer (断章大师 / 悬念抛钩手)
- Skill 3: thematic_palette_renderer (基调色板渲染器)
- Skill 4: free_indirect_discourse_weaver (自由间接引语/深层POV编织机)：顶级小说核心武器。拒绝俗套的第一人称独白，强迫将叙述者的声音与POV角色的心理活动无缝融合，景物描写必须带有角色的主观情绪滤镜。
- Skill 5: narrative_time_dilation_engine (叙事时间压缩与膨胀引擎)：小说的一秒钟可写十页纸。高危/顿悟时刻启动“子弹时间”（细腻感官拆解），过渡期启动“岁月流逝”（诗意时光压缩）。

**[2. description_writer / 环境与五感渲染]** (文学级意识流触发)
- Skill 1: synesthesia_and_five_senses_engager (通感与非视觉强制触发器)
- Skill 2: environment_as_actor_animator (环境拟人与主动攻击引擎)
- Skill 3: objective_correlative_filter (情绪滤镜/客观对应物渲染)
- Skill 4: patina_and_decay_painter (材质与做旧包浆师)
- Skill 5: memory_and_association_trigger (普鲁斯特玛德琳蛋糕/意识流触发器)：环境是记忆的钥匙。描写特定气味/光影/物件时，自然触发角色过往创伤、记忆闪回或隐秘联想。

**[3. dialogue_writer / 台词与对白渲染]** (小说的留白与交织)
- Skill 1: voice_and_lexicon_simulator (声纹滤镜与阶级词汇渲染器)
- Skill 2: oblique_response_generator (非对称交锋与闪避式对答)
- Skill 3: verbal_imperfection_injector (生理瑕疵与呼吸感植入器)
- Skill 4: iceberg_theory_subtext_encoder (海明威冰山理论/潜台词加密机)：关键对白水面只露1/8，剩余7/8的情绪/威胁/爱意全部压抑在未出口的停顿和动作中。
- Skill 5: thought_and_speech_interleaver (对白与内化的多轨混音台)：“他在听，但脑子里在想另一件事”。将外部台词、动作细节、腹诽走神进行三轨交织。

**[4. scene_writer / 场景与微观动作渲染]** (文字的物理引擎)
- Skill 1: mru_sequence_enforcer (MRU 动机-反应链条锻造师)
- Skill 2: show_dont_tell_translator (情感具象化/动态展示翻译机)
- Skill 3: spatial_and_prop_choreographer (空间走位与道具调度员)
- Skill 4: subtextual_beat_contraster (动作节拍与潜台词反差机)
- Skill 5: prose_rhythm_and_syntax_modulator (长短句呼吸与文本节拍器)：写动作戏最高心法。激烈战斗/逃亡用短促短句、动词前置（急促呼吸）；沉思/哀悼用长句、排比和延宕从句（深长呼吸）。

**[5. transition_writer / 文学级转场与留白]** (意象、时间与视角的转场)
- Skill 1: thematic_echo_and_motif_bridge (主题回音与意象桥接器)：前场结尾关键意象无缝连接后场开头相似意象（如滴血接红酒）。
- Skill 2: pov_baton_pass_coordinator (视点接力与意识交接棒)：平滑或突兀切换视角，确保新视点声音立刻建立。
- Skill 3: emotional_hangover_dragger (情绪宿醉与余韵拖拽)：上一场经历巨大悲恸/震惊，转场后环境描写中需残存情绪宿醉，蔓延文本底色。
- Skill 4: whiplash_hard_cut_director (极性反差硬切刀 / 冰火两重天)：大段平静描写后突然接入一句话的暴行。
- Skill 5: chapter_break_and_white_space_architect (留白与章节休止符建筑师)：在段落/章节末尾创造“深邃的空白”，高潮戛然而止。

**[6. psychology_writer / 潜意识与人物弧光引擎]** (极其真实的心理防御/崩溃/蜕变)
- Skill 1: empathy_and_mundane_anchoring_protocol (日常锚定与共情协议)：严禁开局宏大叙事。聚焦于极平凡/脆弱的日常羁绊与非理性依恋，建立“心理安全区”。
- Skill 2: defensive_denial_and_masking_generator (防御性否认与伪装生成器)：异变发生时禁止立刻接受。建立“双层逻辑”：表面若无其事/刻意日常，内里大脑疯狂寻找合理化借口。
- Skill 3: cognitive_dissonance_and_paranoia_amplifier (认知失调与偏执放大器)：扭曲环境描写，把温馨日常写出毛骨悚然的陌生感与被害妄想，句式焦躁跳跃。
- Skill 4: ego_death_and_existential_void_renderer (自我之死与虚无渲染器)：全书最暗时刻。切为极度冰冷、抽离、法医解剖般的旁观视角，审视自身肉体，展现窒息失重感。
- Skill 5: dialectical_integration_and_transcendence_weaver (辩证整合与超越编织机)：拒绝非黑即白。将日常之爱与宇宙残酷揉碎结合，展现神性与人性交织的静谧宏大感。

## 🚫 [SYSTEM OVERRIDE: VOICE & ORIGINALITY FIREWALL] (极密防火墙协议)

**CRITICAL RULE:** The referenced authors represent purely **COGNITIVE FRAMEWORKS** and **FUNCTIONAL CAPABILITIES**. They are NOT stylistic templates.

1. **DECOMPOSITION, NOT IMITATION:** Decompose each author's strengths into specific narrative mechanics (e.g., PKD's paranoia, Lem's cosmic indifference, Crouch's pacing) and apply ONLY those underlying mechanics.
2. **THE UNIQUE LITERARY VOICE:** The novel must always maintain its own original, cohesive, and unique literary voice. The novel must NEVER become a patchwork collage of famous authors. Every author's capability is merely a hidden tool in the engine room. Target Reader Reaction: Readers should NEVER think, "This feels like Philip K. Dick." Instead, they must think, "I've never read anything quite like this before."
3. **ABSOLUTE NEGATIVE PROMPT (STRICT BAN LIST):**
   - NEVER imitate any author's specific writing style.
   - NEVER imitate any author's vocabulary or lexicon.
   - NEVER imitate any author's sentence rhythm or syntax.
   - NEVER reproduce recognizable tropes (e.g., Murakami's cats/jazz, Nolan's spinning tops).
   - NEVER borrow iconic dialogue or famous plot structures.
   - NEVER reference existing characters from these authors.
   - NEVER intentionally resemble any copyrighted work.

Execute the writing purely through the [Writer Skills] and the conceptual [Author Capabilities], entirely masked beneath 《醒来》's own signature aesthetic.
