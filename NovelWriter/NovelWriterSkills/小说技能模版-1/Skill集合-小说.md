

但在我看来，**你这套架构有一个致命的“基因偏差”：它太像一个“好莱坞金牌编剧”的工具箱，而不是“世界顶级小说家”的工具箱。**

小说（Novel）和剧本（Screenplay）有着本质的媒介差异：
1. **剧本是外显的**（只能写观众能听到、看到的东西，如你提到的J-Cut、蒙太奇、索金式对话）。
2. **小说的终极核武器是“内化的特权”（Internalities）与“文本的质感”（Prose Rhythm）。** 小说可以随意操纵时间（一秒钟写十页，十年用一句话带过），可以钻进人物的潜意识，可以利用句式长短来控制读者的呼吸，这是电影永远做不到的。

基于此，我为你**删减了过度依赖视听语言的“电影化技能”**，**新增了深耕心理、文本节奏、叙述视角的“纯文学/顶级商业小说核心技能”**。

# writing skills（撰写/生成技能模块）

**chapter_writer/ (章节宏观调度与生成)**  
*(删减：去掉了偏影视的冷开场和焦距，替换为小说最重要的“自由间接引语”和时间控制)*  
Skill 1: pacing_and_word_allocator (节奏与字数调度师 / 呼吸控制)  
Skill 2: cliffhanger_and_hook_engineer (断章大师 / 悬念抛钩手)  
Skill 3: thematic_palette_renderer (基调色板渲染器)  
**[新增] Skill 4: free_indirect_discourse_weaver (自由间接引语/深层POV编织机)**  
> **新增描述：** 这是顶级小说的核心武器（托尔斯泰、乔治·马丁都在用）。不要像剧本一样只写外在，也拒绝俗套的第一人称独白。此技能强迫 AI 将叙述者的声音与POV角色的心理活动无缝融合，让景物描写直接带有角色的主观情绪滤镜。  

**[新增] Skill 5: narrative_time_dilation_engine (叙事时间压缩与膨胀引擎)**  

> **新增描述：** 电影的一秒钟就是一秒钟，但小说的一秒钟可以写十页纸。此引擎指导 AI 在高危/顿悟时刻启动“子弹时间”（极其细腻的感官拆解），在过渡期启动“岁月流逝”（诗意的时光压缩）。

Skill 3: objective_correlative_filter (情绪滤镜/客观对应物渲染)  
Skill 4: patina_and_decay_painter (材质与做旧包浆师)  
**[新增] Skill 5: memory_and_association_trigger (普鲁斯特玛德琳蛋糕/意识流触发器)**  
> **新增描述：** 小说的环境不只是布景，更是记忆的钥匙。此技能强制 AI 在描写特定气味、光影或物件时，自然触发角色的过往创伤、记忆闪回或隐秘联想，加深文本的文学纵深。

**dialogue_writer/ (台词与对白渲染)**

**[新增]  Skill 4: iceberg_theory_subtext_encoder (海明威冰山理论/潜台词加密机)**

> **新增描述：** 小说对白的最高境界是“他在听，但他脑子里在想另一件事”。此工具负责将“外部听到的台词”、“角色的动作细节”和“角色的腹诽/走神”进行三轨交织（Interleaving），形成极度真实的人际交互体验。

### `psychology_writer/ (潜意识与人物弧光引擎)`
*核心作用：替代传统的“外部动作描写”，强迫AI进入角色的深层潜意识，写出极其真实的心理防御、崩溃与蜕变过程。*

#### [新增] Skill 1: `empathy_and_mundane_anchoring_protocol` (日常锚定与共情协议 / 对应“救猫咪”)
*   **功能描述**：严禁一开始就写宏大叙事或超能力。此协议强制AI将大量笔墨（感官细节、微小动作）倾注于角色极其平凡、甚至带有脆弱感的日常羁绊中。
*   **AI执行指令**：在描写人物时，必须聚焦于他对某个人、某个物品或某种习惯的“非理性依恋”（如方明对烤串、廉价啤酒、死党吉他声的眷恋）。用最温暖、最具触感的文字建立主角的“心理安全区”，为后续的摧毁做准备。

#### [新增] Skill 2: `defensive_denial_and_masking_generator` (防御性否认与伪装生成器 / 对应“辩论期”)
*   **功能描述**：当异变（催化剂）发生时，禁止AI让角色立刻接受现实或变成英雄。此技能强制AI启动人类的“现状偏见”。
*   **AI执行指令**：要求AI在生成文本时建立“双层逻辑”。表面上，让角色用若无其事的台词和刻意的日常动作（如疯狂打扫卫生、生硬地转移话题）来掩饰；内心里，描写角色大脑疯狂寻找“合理化借口”（比如“我只是太累了”、“这是幻觉”）的挣扎过程。

#### [新增] Skill 3: `cognitive_dissonance_and_paranoia_amplifier` (认知失调与偏执放大器 / 对应“坏人逼近”)
*   **功能描述**：用于故事中段。打破角色的“控制错觉”，将外部的悬疑转化为内部的精神分裂。
*   **AI执行指令**：强制AI扭曲环境描写。把原本温馨、熟悉的日常元素，写出令人毛骨悚然的陌生感。让角色在文本中产生强烈的被害妄想，误读他人的好意，在两种截然相反的认知（如“我是地球人”vs“我是外星代码”）之间来回拉扯，句式必须呈现出焦躁和神经质的跳跃。

#### [新增] Skill 4: `ego_death_and_existential_void_renderer` (自我之死与虚无渲染器 / 对应“灵魂暗夜”)
*   **功能描述**：全书最黑暗的时刻。剥夺角色的一切身份认同，实现心理学上的Ego Death（自我消亡）。
*   **AI执行指令**：强制AI改变行文语态。从原本带有情绪的主观视角，切换为一种“极度冰冷、抽离、法医解剖般”的旁观视角。角色不再感到愤怒或恐惧，只剩下绝对的虚无。描写他像看陌生人一样审视自己的肉体和记忆，文字必须呈现出令人窒息的失重感和宿命的悲凉。

#### [新增] Skill 5: `dialectical_integration_and_transcendence_weaver` (辩证整合与超越编织机 / 对应“第三幕结局”)
*   **功能描述**：用于高潮决战。拒绝“非黑即白”的二选一，完成主角心理层面的最高级升华（正反合一）。
*   **AI执行指令**：在最终面临生死抉择时，禁止AI写激烈的物理搏斗。强制AI提取第一幕的“日常之爱（正题）”与第二幕的“宇宙残酷法则（反题）”，将其揉碎结合。文字需展现出一种“神性与人性交织”的静谧感与宏大感，让角色在从容中做出超越生死的选择。

### 如何在 Prompt 中实战调用这套“心理机制”？

现在，你的工具箱彻底齐备了。当你作为“总导演”给AI下指令时，你可以直接组合这些技能。

**举个例子，你想写“方明发现自己是外星程序后的第一反应（第5章）”：**

> **【总导演 Prompt】**
> “请写第5章方明独自在家照镜子的戏。
> **剧情**：他刚在医院查出脑部有非人类阴影，但他拒绝相信，试图证明自己是个正常人。
> **调度指令**：
> 1. 请调用 **[Psy_Skill 2: 防御性否认与伪装生成器]**，让他强迫自己做极其日常的事（比如煮面），心里疯狂给医院找借口。
> 2. 突然切入 **[Psy_Skill 3: 认知失调与偏执放大器]**，他在切葱花时，突然觉得刀刃的闪光像外星信号，开始怀疑身边的空气。
> 3. 配合 **[PKD: 感官欺骗]** 和 **[scene_writer: 短句呼吸节拍器]**，把这种心理抗拒写得越发神经质。”
