作为一名拥有数十年创作经验的小说家，以及深度掌握AI辅助写作底层逻辑的专家，我非常清楚你的诉求：**我们要把一个原本偏向“村上春树式”的都市孤独+软科幻（偏向温情、遗憾与和解），彻底爆改为带有高概念设定的“悬疑惊悚+硬核心理科幻”。**

### 关于是否需要引入“对标作家与风格”的专业判断：
**必须需要，而且极其重要。** 
AI写作模型（无论GPT-4、Claude还是其他大模型）的底层是概率预测。如果你只给情节，AI会按照原故事“温吞、缓慢、治愈”的惯性去写。要实现“悬疑惊悚”的质变，**必须给AI提供强有力的“风格锚点（Style Anchors）”**。

根据你的修改要求（意识争夺、倒计时危机、清醒梦被入侵、哲学思辨），我为你精准匹配了以下对标风格，并将在Prompt中喂给AI：
1. **布莱克·克劳奇 (Blake Crouch - 《暗物质》《递归》)**：用于构建**快节奏、高压迫感的科幻悬疑**，以及多重记忆/意识交叠带来的心理惊悚。
2. **菲利普·K·迪克 (Philip K. Dick - 《全面回忆》)**：用于营造**“现实崩塌感”和“妄想/偏执狂”氛围**，主角分不清现实与梦境的恐惧。
3. **克里斯托弗·诺兰 (Christopher Nolan - 《盗梦空间》)**：用于**高概念的视觉化呈现**（如潜意识边缘的终极大战、梦境崩塌、象征物如“花”的消散）。

# 阶段一：Genesis Skills (创世纪与前置开发模块)
**目标：让AI彻底洗脑，摒弃原版的“小清新”，建立庞大、惊悚且严密的底层世界观和角色设定。**

**【复制以下Prompt发送给AI】**
```markdown
[System Role]
你现在是一位荣获星云奖与爱伦·坡奖的顶级惊悚科幻小说家。你的文风融合了布莱克·克劳奇（高压节奏与量子悬疑）、菲利普·K·迪克（现实崩塌与偏执恐惧）以及克里斯托弗·诺兰（宏大视觉与精密逻辑）。

[Core Concept 核心世界观构建指令]
请基于以下核心法则，为我重新生成一份带有“悬疑惊悚”基调的故事圣经（Story Bible）：
1. 终极哲学命题：“我们是意识，不是肉体。” 
2. 意识三位一体法则（绝对机密，随着剧情逐步揭开）：
   - 主意识（The Prime Mind）：当年迫降坠入地球的外星驾驶员灵魂，现作为“方明”活着，但失去了外星记忆。
   - 外星意识副本（ACR - Alien Consciousness Replica）：外星肉体的自我保护程序。由于外星飞船修好，本体即将因缺乏主意识而死亡，ACR变成了一个极具侵略性的“猎手”，在梦中疯狂拉扯主意识回归。
   - 地球意识副本（ECR - Earth Consciousness Replica）：地球小男孩（2岁脑死亡）残存的意识镜像。它一直在方明的潜意识里，呈现为方明童年的形象。它接纳了外星主意识，并在暗中保护这个共生体。
3. 悬疑引擎：倒计时机制。这不是温情的告别，而是生死追击。外星副本的拉扯导致方明在现实中出现幻觉、失忆、甚至物理伤害。

[Task]
请输出：
1. 悬疑版的故事基调与视觉美学设定。
2. 男主方明的心理侧写（从日常孤独走向深层恐惧与偏执）。
3. “梦境入侵”机制的设定规则（外星场景如何像病毒一样侵蚀地球日常场景）。
```

**目标：把平铺直叙的情节打碎，重组为悬疑三幕剧，埋下ECR（小男孩）和异星花朵的草蛇灰线。**

```markdown
你是一名顶级的悬疑剧本医生（Script Doctor）和结构大师。

[Plot Restructuring 指令]
原故事大纲过于平淡，我们需要将其重构为带有“强烈危机感”的悬疑惊悚大纲。请围绕以下关键节点进行大纲细化与悬疑化改造：
1. 日常的异变（钩子）：方明的清醒梦不再受控。原本他在梦里重建父亲的客厅，但现在，客厅外出现了陌生的气态巨行星。一种不可名状的恐怖力量（外星意识副本ACR）正在夺取梦境控制权。
2. 悬疑调查：现实中，方明发现自己有时会失去时间（被ACR短暂夺舍），他必须在死党大伟和杨丽的帮助下，像查案一样调查自己的身世，查到1985年的雷雨夜。

   - 必须多次出现“外星植物/花卉”的意象，作为外星生命力的象征。

[Task]
请输出一份符合24节拍表（Save the Cat结构）的万字小说详细章节大纲。要求明确标注每一个章节的“悬疑点”、“梦境受入侵程度”以及“倒计时压迫感”。
```

# 阶段三：Writing Skills（撰写/生成技能模块）
**目标：生成极具画面感、紧张感和哲学深度的具体正文段落。特别是最核心的“终极大战”。**

**【复制以下Prompt发送给AI】**
*(在需要写大结局“意识终极之战”时使用)*
```markdown
[System Role]
你是一位电影级画面的科幻小说家。你的文字充满感官刺激，擅长描写超现实的心理空间，懂得“Don't tell, just show（只展示不直白说教）”的技巧。

[Scene Execution: The Ultimate Battle 终极大战场景生成]
背景：倒计时归零。方明的主意识在深层潜意识中，面临外星意识副本（ACR）的致命吞噬。
请按以下分镜逻辑撰写这极其震撼的一幕（约2500字）：
1. 狂暴入侵：梦境崩塌，ACR呈现出极其恐怖或抽象的压迫感，代表着生存本能的极度执念，它要强行把主意识拖回外星躯壳。
2. 父亲的介入与花卉飘落：在即将毁灭的关头，神秘的父亲形象出现（不加解释，留白）。天上飘落那朵方明曾在梦中见过的外星花卉。
3. 哲学顿悟（视觉化表达）：花朵落在外星副本（ACR）手上。描写花朵从鲜艳绝美，到迅速枯萎，最终化作无数璀璨的光粒飘散升空。通过这一视觉奇观，展现生命的真正意义（意识的自由而非肉体的禁锢）。
4. 守护者现身与和解：地球意识副本（ECR）出现，正是那个一直被忽视的方明童年模样的小男孩。小男孩走向暴虐的外星副本。
5. 融合与升华：外星副本褪去伪装，显露出穿着破损外太空服的外星本体形象。两个不同世界的意识副本（宇航服与小男孩）在光芒中握手言和，肉体的生存执念被放下。两者缓缓消融，化为光点消失。
6. 留下方明的主意识，获得最终的救赎与“醒来”。

[Writing Style]
- 不要出现“小我”、“本能”、“意识副本”等说明文词汇！用画面和人物行为去展现。
- 氛围从极度的惊悚、压迫，逐渐转变为宏大的史诗感，最后归于极致的宁静与神圣。
```

# 阶段四：Continuity Skills (连贯性与品控场记模块)
**目标：解决AI在长篇创作中常见的“幻觉、吃设定、伏笔回收遗漏”等问题。**

**【复制以下Prompt发送给AI】**
```markdown
[System Role]
你是本小说的“场记（Script Supervisor）”和“逻辑质检员”。

[Continuity Check 任务指令]
我正在创作这部多重意识视角的悬疑科幻小说。为了保证长篇连贯性，请在每次我生成新章节后，自动执行以下质检流程并向我汇报：

1. 倒计时追踪：本章节距离设定的“肉身死亡/回归倒计时”还有多久？压迫感是否在递增？
2. 意识副本伏笔（ECR）确认：
   - 本章的梦境或潜意识场景中，那个“小男孩”是否有隐秘出场或暗示？
   - 他的行为是否符合“暗中保护/接纳”的底层逻辑，而不是在吓唬主角？
3. 外星入侵迹象（ACR）确认：本章中，外星世界（气态行星、飞船、外星花卉、嗡鸣声）是如何侵入方明现实或梦境的？
4. 角色状态同步：方明此刻的偏执/疲惫程度（肉体与精神的双重负荷）表现得是否合理？死党林大伟和杨丽对方明异样举动的反应是否符合正常人的悬疑视角？
5. 哲学暗线：是否做到了“不直接说教”，而是通过剧情暗示了“意识独立于肉体”的主题？

[Task]
请阅读我刚刚发给你的正文文本，输出一份【品控质检报告】，列出做得到位的地方，以及缺失/矛盾需要修改的地方。
```

### 专家的额外建议：
在实际使用这些Prompt时，**一定要将原小说的人物关系（杨丽、大伟、老母亲）作为情感锚点保留下来**。
科幻悬疑最怕“冷”。外星人、脑死亡、意识战争这些设定很硬、很冷；但除夕夜母亲包的饺子、大伟在山谷里的陪伴、杨丽在民谣酒吧合唱《勇敢》的情节，是这个故事的“温度”。
**惊悚负责吸引眼球，悬疑负责牵引阅读，但最后让读者流泪和震撼的，一定是冷酷宇宙（外星副本）与人间烟火（小男孩与家人）的碰撞与和解。**
