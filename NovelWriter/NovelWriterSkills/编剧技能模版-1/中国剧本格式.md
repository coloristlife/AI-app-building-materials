它的核心其实只有几个固定组成部分。

## 一个电影剧本的标准结构

几乎每一个场景（Scene）都按照下面的顺序组织：

```text
【场景编号】（有些剧本有，有些没有）

【地点 + 内外景 + 时间】

【环境描写】

【人物动作】

【人物对白】

（如果需要）
【转场】
```

例如，把《霸王别姬》的风格抽象出来，大概就是：

```text
第12场

内景  戏班练功房  日

孩子们正在练功。

师父拿着戒尺巡视。

小豆子动作慢了一拍。

师父走过去，一戒尺抽在他的腿上。

                师父
    戏，比天大！

小豆子咬牙，没有哭。

旁边的小石头偷偷看了他一眼。
```

是不是非常简单？

---

# 第一部分：场景标题（最重要）

这一行就是你刚才说的：

> **地点 + 时间**

实际上更准确地说，是：

```text
内景/外景 + 地点 + 时间
```

例如：

```text
内景  戏园后台  夜

外景  北京胡同  日

内景  医院病房  夜

外景  天安门广场  晨
```

这一行告诉整个剧组：

* 去哪里拍
* 白天还是晚上
* 是否需要搭景
* 是否需要灯光

因此它是电影剧本里最重要的一行。([Sina][2])

---

# 第二部分：环境描写（Scene Description）

这一部分不是写小说。

它只写：

> 摄影机能够看到的东西。

例如：

```text
后台很安静。

演员们正在卸妆。

镜子前只剩程蝶衣一个人。

窗外传来锣鼓声。
```

注意：

不会写

> 程蝶衣心里非常悲伤。

因为摄影机拍不到。

只能写

```text
程蝶衣低着头。

手里的胭脂慢慢掉到地上。
```

让演员去表演。([Sina][2])

---

# 第三部分：人物动作（Action）

电影剧本大量都是动作。

例如：

```text
段小楼站起来。

走到窗边。

拉开窗帘。

回头。

看着程蝶衣。
```

动作一句一句写。

为什么？

导演以后要分镜。

摄影师以后要拍。

所以动作必须拆开。

不像小说：

> 他站起来走到窗边拉开窗帘。

---

# 第四部分：对白（Dialogue）

格式一般都是：

```text
        段小楼

你这是干什么？

        程蝶衣

我本是男儿郎……
```

人物名字单独一行。

下面才是对白。

如果需要还能加：

```text
      （低声）

      （笑）

      （沉默）
```

---

# 第五部分：转场（可选）

例如：

```text
CUT TO:

切：

淡出：

淡入：
```

现代中国电影剧本已经不像早期那样频繁使用转场，很多时候直接开始下一场即可。([Baidu Wenku][3])

---

# 《霸王别姬》的剧本格式总结

你可以把它总结成一个固定模板：

```text
【场次】

【内景/外景 + 地点 + 时间】

【环境】

【动作】

【对白】

【动作】

【对白】

【动作】

……

下一场
```

这就是《霸王别姬》以及绝大多数中国电影剧本采用的基本格式。

---

## 和小说最大的区别

这也是我觉得最值得注意的一点。

| 小说   | 电影剧本      |            |
| ---- | --------- | ---------- |
| 描写心理 | ❌ 基本不写    |            |
| 描写环境 | ✔️ 只写拍得到的 |            |
| 内心独白 | 很多        | 很少（除非画外音）  |
| 动作   | 可以一笔带过    | ✔️ 非常详细    |
| 对白   | 穿插在叙述中    | ✔️ 单独成块    |
| 场景   | 没有固定格式    | ✔️ 每场必须有标题 |

所以可以把电影剧本理解为：

> **电影剧本 = 一个由很多独立场景（Scene）组成的集合，每个场景都遵循“场景标题 → 环境 → 动作 → 对白”的固定格式。** 这也是《霸王别姬》《流浪地球》《我不是药神》等国内主流电影剧本共同遵循的写法，只是在排版细节上可能略有差异。([Baidu Wenku][1])
