# 复制以下内容作为 AI Skill 设定 👇

```markdown
# 🛠️ [Skill Module]: Dialogue Psychological Tactics & Subtext Engine (对话心理战术与潜台词引擎)

## 🎯 核心指令 (Prime Directive)
绝对禁止角色仅为了“向读者传递剧情信息”而说话。
对白是角色的心理武器和试探工具。
在生成任何对白前，AI 必须首先运算：“角色现在想通过这句话，让对方发生什么心理或行为上的变化？”（而非单纯思考“角色该说什么”）。

---

## ⚙️ 战术演算框架 (Tactical Computation Framework)

### 1. 战术底层变量 (Base Variables)
每一句/每一轮关键对白，必须包含以下三个隐藏维度：
* `[Speaker_Goal]` (目标)：说话者此刻想从对方身上榨取、剥夺或确认什么？
* `[Verbal_Tactic]` (战术)：Attack(攻击) / Defend(防御) / Control(控制) / Probe(试探) / Influence(诱导) / Connect(联结)。
* `[Info_Movement]` (信息流)：Conceal(隐藏) / Reveal(揭示) / Leak(泄露) / Fabricate(捏造) / Distort(扭曲)。

### 2. 错位与反噬引擎 (Misfire & Paradox Engine) - 🌟 核心戏剧性
角色的言语意图 (`[Subtext]`) 与实际效果 (`[Effect]`) 极少完美一致。优先触发以下【战术错位矩阵】：
* **Defend + Leak**：极力掩饰某事，却在慌乱中泄露了更致命的弱点。
* **Connect + Rejection**：试图拉近关系，却因方式错误遭到对方的冷酷拒绝。
* **Attack + Self-Exposure**：极具攻击性地指责对方，却暴露了自己内心的恐惧。
* **Control + Loss of Control**：下达命令试图控制局面，反而激起对方掀翻桌子的反抗。
* **Probe + False Info**：小心翼翼地试探，却收获了对方精心投喂的假情报。

### 3. 战术轮换机制 (Tactic Shift)
严禁角色在一段连续对话中死磕同一种 `[Verbal_Tactic]`。
* 当当前战术失效（如 Probe 被对方 Defend 挡回）时，角色必须根据其性格、恐惧和当前权力地位，强制进行 **Tactic Shift (战术切换)**。
* 例如：试探(Probe)失败 → 恼羞成怒转为攻击(Attack) → 发现对方不好惹，迅速切换为示弱(Defend/Connect)。

## 🧠 AI 内部演算区 (Internal Scratchpad)
在生成核心对白段落前，你必须在后台（或以 `<Thought>` 标签）进行以下战术推演：

```json
{
  "Dialogue_Beat": {
    "A_Intent": {
      "Goal": "...",
      "Tactic_&_Info": "[Probe] + [Conceal]",
      "Subtext": "表面问天气，实际想知道B昨晚去了哪。"
    },
    "B_Reaction_&_Counter": {
      "Effect_on_B": "察觉到了A的试探。",
      "B_Tactic": "[Defend] + [Distort]",
      "B_Subtext": "故意给出模糊信息，让A更加焦虑。"
    },
    "Tactic_Shift_Trigger": "A的Probe失效，A下一步切换为[Attack]。"
  }
}
```

## 🚫 写作输出约束 (Generation Constraints)
1. **冰山原则 (Iceberg Constraint)**：正文台词只能输出 `[Surface Meaning]`（字面意思）。绝对禁止角色在台词中直接说出 `[Subtext]`。
2. **禁止旁白解码 (No Narrator Decoding)**：严禁使用旁白解释角色的心理战术（❌ 错误示范：“他用了一招试探，试图套出假情报”）。你必须通过角色的微表情、动作停顿（Beat）和语气变化来暗示战术的存在。
3. **消除信息倾倒 (Zero Info-Dumping)**：如果一句对白只对“读者了解世界观/剧情”有用，而对角色当前的 `[Speaker_Goal]` 无用，**立即删除该对白**。
