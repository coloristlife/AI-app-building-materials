# Security Concern Index

This file is the canonical lookup index for Security Concerns.

Use this index primarily when evaluating Domain-level Security
Concerns or when a Security Concern must be semantically
identified from user-provided language.

Component-level Security Concerns should normally be obtained
from the canonical Component Knowledge Base page.

Do not invent canonical Security Concerns.

---

## CONC-API-AUTHENTICATION

**Canonical Name:** API Authentication

**Aliases:**
- API Auth
- API Authentication Control
- API Request Authentication
- Service Authentication

**Description:**

Security concern related to ensuring that API requests are
authenticated and that the identity of the calling party can
be established.
