# API Security

## Description

Security controls protecting APIs from unauthorized
access, manipulation, abuse, and unintended exposure.

## Applicability

This Concern applies when:

- The system exposes APIs.
- External or internal clients invoke APIs.
- APIs expose business functionality.
- APIs provide access to protected resources.
