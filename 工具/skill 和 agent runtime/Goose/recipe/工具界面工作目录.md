

goose 聊天输入框中，左下角的文件夹**绝对不是**用来配置“Skill（技能）”或“Recipe（配方）”文件位置的。

让我们用一个简单的比喻来区分这两者的关系：

* **Skill/Recipe 文件** = AI 的**“工具箱”或“大脑记忆”**（它怎么做安全审查、它懂哪些规矩）。
* **左下角的文件夹** = AI 的**“手术台”或“目标工地”**（你今天想让它审查哪一段具体的代码）。

### 详细区分：

#### 1. 你的 Skill / Recipe 文件应该放哪？
系统已经自动管理了这些文件。正如我们之前发现的，当你加载一个 Recipe 时，Goose 会默认把它保存在 `~/.config/goose/recipes` 里。
**你完全不需要在左下角去选中这个配置目录。** 只要文件导入了，Goose 的大脑就已经学会了这个技能，随时可以在任何地方使用。

#### 2. 左下角的文件夹（工作目录）该选什么？
你应该选择**你真实要处理的项目代码**或**文档所在的文件夹**。

**举个实际的例子：**
假设你在桌面上有一个项目叫 `my-website`（你的个人网站代码），你现在想用 Goose 给你写好的 `security-review`（安全审查代码技能）来检查这个网站有没有漏洞。

**正确的操作步骤是：**
1. 点击左下角文件夹，选中桌面上的 `my-website` 文件夹。 （告诉它：“站到这个工地上来”）
2. 在界面的输入框里调用你的 Recipe，或者直接发指令：“开始安全审查”。（告诉它：“使用你大脑里的审查技能”）
3. Goose 就会自动在 `my-website` 文件夹里翻阅你的 HTML、Python 源码，寻找安全漏洞。

**总结：**
不要把左下角的路径指向你的 `.yaml` 或 skill 配置文件！**把它指向你真正想让 AI 帮你干活的那一堆文件/代码所在的目录。**


在执行过程中， goose会执行下面的命令，找到所有的Markdown文件
```
  
find 工作文件夹 -name "*.md"
```
