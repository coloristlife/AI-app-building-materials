

## 来源经验

用户经验原文：

> "年线（250MA）是机构长期成本线。走平向下意味着存量博弈或熊市，只做超跌反弹，不做格局；年线拐头向上代表长牛确立，回踩年线是中线确定性极高的'倒车接人'点。"

核心逻辑：250日均线（年线）代表机构长期持仓成本区域，其形态（走平/向下 vs 拐头向上）决定了当前市场处于存量博弈/熊市还是长期牛市；不同市场状态下应采取不同的交易策略——熊市阶段仅做短线超跌反弹，牛市确立后回踩年线是中线布局的高确定性买点。

## 一、目的

利用年线（250MA）的形态和斜率，识别当前市场所处的宏观阶段（熊市/存量博弈 vs 长期牛市），从而决定应采取"仅做超跌反弹的短线策略"还是"可进行中线布局的回踩买入策略"。

本法则用于判断市场整体格局归属，不用于精确预测短期价格走势，也不保证回踩年线后必然反弹。

## 二、适用范围

### 适用情形

- 年线（250MA）走平或向下 → 判定为存量博弈或熊市阶段
- 年线（250MA）拐头向上 → 判定为长期牛市确立
- 价格回踩年线（250MA）附近

### 不适用情形

- 用户未明确提供排除情形。
- **AI补充解释 / 限制说明**：本法则基于250日均线这一中长期指标，不适用于判断日内或超短线价格波动；若标的上市时间不足250个交易日，年线数据不完整，法则可能无法评估，此为AI补充的谨慎提示，非用户原始经验。

## 五、评估逻辑

### 观察条件

- 观察A：年线走平或向下
- 观察B：年线拐头向上
- 观察C：当前价格回踩至年线附近

（注："走平""拐头向上"的具体斜率数值阈值，用户未明确定义，保留为定性描述。）

### 判断逻辑

```text
若 年线形态 = 走平 或 向下

则
解读：市场处于存量博弈或熊市阶段
动作：仅考虑超跌反弹（短线），不进行中线布局（不做格局）

否则，若 年线形态 = 拐头向上

则
解读：长期牛市趋势确立

  若 当前价格 回踩至年线附近

  则
  解读：处于中线确定性较高的买入区域（"倒车接人"点）
  动作：可考虑中线买入（BUY / SCALE IN）

  否则
  规则状态：无法判断（INCONCLUSIVE，未回踩，暂无中线买点信号）

否则
规则状态：数据不足（INSUFFICIENT_DATA）
```

### 解读

- 年线走平或向下：反映机构成本线未能有效抬升，市场缺乏趋势性机会，仅存在短线超跌修复行情。
- 年线拐头向上且价格回踩：反映市场已从存量博弈转向趋势性上涨，回踩年线是对新趋势的确认性验证，属于中线较高确定性的介入点。

### 建议动作

- 年线走平/向下：短线超跌反弹操作（不做中线布局）
- 年线拐头向上 + 价格回踩年线：中线买入 / 加仓（BUY / SCALE IN）
- 年线拐头向上但未回踩：等待（WAIT）

## 六、输出

### 规则状态

已触发 / 未触发 / 无法判断 / 数据不足 （TRIGGERED / NOT_TRIGGERED / INCONCLUSIVE / INSUFFICIENT_DATA）

### 解读

根据年线形态判断当前市场处于熊市/存量博弈还是长期牛市，并结合价格是否回踩年线，判断是否存在中线买入机会。

### 建议动作

- 熊市/存量博弈 → 仅做超跌反弹（短线操作）
- 牛市确立 + 回踩年线 → 中线买入（BUY / SCALE IN）
- 牛市确立但未回踩 → 等待（WAIT）
- 数据不足 → 仅供参考（INFORMATIONAL ONLY）

### 证据

触发时应列出：年线数值走势、年线斜率方向、当前价格与年线的相对位置。

### 缺失输入

- "走平"与"拐头向上"的具体斜率判定标准（用户未定义）
- "回踩"年线的具体偏离度范围（如价格距年线多近算"回踩"，用户未定义）
- 标的历史数据是否满250个交易日（若不足则无法计算年线）

## 七、局限性

- 不能确认熊市何时结束或牛市何时开始，仅为对当前年线状态的定性判断
- 不能保证回踩年线后价格必然反弹，"倒车接人"仅代表历史经验中的高确定性区域，非必然结果
- "走平""拐头向上""回踩"均缺乏明确数值定义，判断存在主观性
- 不适用于上市时间不足250个交易日、年线数据不完整的标的（详见"AI补充解释"部分）
- 不替代仓位管理、止损纪律等风险控制规则
- 该法则基于中长期均线，无法用于日内或超短线交易决策
