# 规则：账户曲线的"等仓复利"法则（核心命脉）

## 来源经验

用户经验原文：

> "纪律一（等仓出击）：每笔交易仓位必须恒定（如每只票固定1成仓）。杜绝'赚时轻仓试水，亏时重仓死扛'的恶习。 纪律二（积小胜为大胜）：追求'小赚+小亏+偶有大赚'的平滑曲线，严禁出现单笔大亏。一旦连续两笔止损，立即暂停交易，调整心态而非加码赌命。 纪律三（止损铁律）：任何买入逻辑失效（破位、板块退潮）时，无论盈亏，必须无条件离场，将单笔亏损严格控制在总资金的2%以内。"

核心逻辑：本经验是关于资金/仓位管理的三条独立纪律，用户已用"纪律一/二/三"明确将其拆分为三个不同层面的规则——① 仓位分配规则（每笔交易仓位恒定）；② 连续止损后的熔断规则（连续两次止损即暂停交易）；③ 单笔止损执行规则（逻辑失效即离场，亏损上限2%）。三者触发场景（建仓时 / 连续亏损后 / 逻辑失效时）、评估对象（仓位大小 / 交易节奏 / 离场时机）、以及建议动作完全不同，按拆分原则分为**三条独立法则**。

## 一、目的

规定当买入逻辑失效（如价格破位、所属板块退潮）时，无论当前盈亏状态如何，都必须无条件离场，并将单笔交易的最大亏损严格控制在总资金的2%以内，以此作为控制单笔风险敞口的底线纪律。

本法则是一条基于"逻辑是否仍然成立"和"亏损是否触及上限"的强制离场规则。

## 二、适用范围

### 适用情形

- 当初买入该标的所依据的逻辑已经失效，具体表现为：
    - 价格发生破位（跌破关键支撑位/技术形态被破坏）
    - 所属板块/题材出现退潮迹象
- 或者，该笔交易的浮动亏损已达到总资金的2%

### 不适用情形

- 用户未明确提供排除情形。
- **AI补充解释 / 限制说明**：本法则要求"无论盈亏"都要离场，意味着即使当前该笔交易仍为盈利状态，只要买入逻辑已经失效，也应离场了结，而非仅在亏损时才执行，此为对用户原文"无论盈亏"的忠实强调，而非新增假设。

| 输入项               | 类型                | 需要原因                                      |
| ----------------- | ----------------- | ----------------------------------------- |
| 当初买入逻辑的具体内容       | 用户上下文             | 用于判断"逻辑是否失效"的比较基准，需用户提供                   |
| 当前价格是否发生破位        | 市场数据 / 衍生数据       | 判断技术面逻辑是否失效的核心依据之一                        |

## 五、评估逻辑

### 观察条件

- 观察A：价格发生破位，或所属板块出现退潮迹象（买入逻辑失效）
- 观察B：该笔交易的浮动亏损占总资金比例已达到或超过2%

（注：具体"破位"的技术定义及"退潮"的判定标准，用户未明确给出量化阈值，保留为定性描述；"总资金2%"这一亏损上限则为用户明确给出的量化标准。）

### 判断逻辑

```text
若 买入逻辑 = 已失效（价格破位 或 板块退潮）

则
解读：当初持有的依据已不再成立
动作：无条件离场（EXIT），无论当前盈亏

否则，若 该笔交易浮动亏损 ≥ 总资金的2%

则
解读：已触及单笔风险控制上限
动作：无条件离场（EXIT）

否则
规则状态：未触发（NOT_TRIGGERED）
```

### 解读

本法则的核心是"逻辑优先于盈亏"——只要当初买入的理由不再成立，就应离场了结，即使当前仍是盈利状态；同时设置了2%的硬性亏损上限作为兜底风控，防止因逻辑判断分歧或犹豫而导致单笔亏损失控。

### 建议动作

无条件离场（EXIT）

## 六、输出

### 规则状态

已触发 / 未触发 / 无法判断 / 数据不足

### 解读

判断买入逻辑是否已失效，或该笔交易亏损是否已触及总资金2%的上限，从而是否应立即离场。

### 建议动作

- 触发（逻辑失效 或 亏损达2%）→ 无条件离场
- 未触发 → 仅供参考

### 证据

触发时应列出：当初买入逻辑内容、当前价格/板块状态与逻辑失效的具体表现、当前浮动盈亏占总资金的比例。

### 缺失输入

- 当初买入的具体逻辑（需用户提供，否则无法判断是否"失效"）
- "破位"的具体技术定义（如跌破哪条均线或哪个价位）
- "板块退潮"的具体判定标准
- 用户总资金规模及该笔交易的仓位占比（用于计算2%亏损上限）

## 七、局限性

- 不能自动判断买入逻辑是否失效，高度依赖用户对自身买入逻辑的准确记录和如实反馈
- "破位""退潮"缺乏统一量化标准，判断存在主观性
- 2%的亏损上限是用户明确给出的量化标准，但计算依赖用户提供的总资金规模及仓位占比信息，若信息缺失则无法准确计算
- 不替代对买入逻辑本身合理性的评估，仅约束逻辑失效后的离场执行纪律
- 不能区分"逻辑失效"与"短期正常波动"，误判可能导致过早离场

## AI补充解释

本法则中的用户经验已相对具体明确（尤其"2%"这一量化标准由用户直接给出），AI未引入额外的实质性假设，仅对"无论盈亏"这一表述的适用范围做了必要强调（见"不适用情形"部分）。

## 需向用户澄清的问题

- "价格破位"具体指跌破什么参考位？（如某条均线、前期支撑位、箱体下沿等）
- "板块退潮"具体通过什么信号判断？（如板块指数走势、板块内个股普遍下跌、题材热度数据等）
- 总资金规模及每笔交易的标准仓位占比分别是多少，以便准确计算2%的亏损上限对应的具体金额或价格跌幅？
