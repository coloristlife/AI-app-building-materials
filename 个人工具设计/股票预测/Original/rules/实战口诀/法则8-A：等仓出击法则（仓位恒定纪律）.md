
## 来源经验

用户经验原文：

> "纪律一（等仓出击）：每笔交易仓位必须恒定（如每只票固定1成仓）。杜绝'赚时轻仓试水，亏时重仓死扛'的恶习。 纪律二（积小胜为大胜）：追求'小赚+小亏+偶有大赚'的平滑曲线，严禁出现单笔大亏。一旦连续两笔止损，立即暂停交易，调整心态而非加码赌命。 纪律三（止损铁律）：任何买入逻辑失效（破位、板块退潮）时，无论盈亏，必须无条件离场，将单笔亏损严格控制在总资金的2%以内。"

核心逻辑：本经验是关于资金/仓位管理的三条独立纪律，用户已用"纪律一/二/三"明确将其拆分为三个不同层面的规则——① 仓位分配规则（每笔交易仓位恒定）；② 连续止损后的熔断规则（连续两次止损即暂停交易）；③ 单笔止损执行规则（逻辑失效即离场，亏损上限2%）。三者触发场景（建仓时 / 连续亏损后 / 逻辑失效时）、评估对象（仓位大小 / 交易节奏 / 离场时机）、以及建议动作完全不同，按拆分原则分为**三条独立法则**。

---


## 一、目的

规范每笔交易的建仓仓位大小，要求保持恒定，杜绝因主观情绪（盈利后轻仓试探、亏损后重仓摊薄）导致仓位分布失控，从而保护账户整体风险结构的一致性。

本法则是一条建仓时的仓位约束规则，不涉及具体标的的买卖时机判断。

## 二、适用范围

### 适用情形

- 每一笔新建仓交易（无论标的、无论此前该笔交易或近期交易的盈亏结果）

### 不适用情形

- 用户未明确提供排除情形。
- **AI补充解释 / 限制说明**：本法则约束的是"单笔标准仓位"是否恒定，不排斥用户基于总体仓位管理（如法则三-B"分批低吸"、法则三-C"重仓跟进"）在不同确定性阶段使用不同仓位单位，但每个仓位单位本身（如"1成仓"这一基准）应保持恒定，此为对"等仓"含义的必要澄清，非新增限制。

## 三、所需输入

| 输入项           | 类型    | 需要原因                                           |
| ------------- | ----- | ---------------------------------------------- |
| 用户设定的标准单笔仓位比例 | 用户上下文 | 用户凭自身判断或掌握的信息直接告知：核心基准值，需用户明确告知（如"1成仓"）        |
| 本次拟建仓仓位比例     | 用户上下文 | 用户凭自身判断或掌握的信息直接告知：需与标准仓位比较，判断是否偏离              |
| 近期交易盈亏状态      | 用户上下文 | 用户凭自身判断或掌握的信息直接告知：用于判断本次仓位调整是否受"赚时轻仓、亏时重仓"情绪驱动 |

## 四、证据来源

| 输入项       | 来源                 |
| --------- | ------------------ |
| 标准单笔仓位比例  | 用户提供 / 需用户确认       |
| 本次拟建仓仓位比例 | 用户提供（用户下单前告知或系统记录） |
| 近期交易盈亏状态  | 用户提供 / 需用户确认       |

## 五、评估逻辑

### 观察条件

- 观察A：用户存在预设的标准单笔仓位比例
- 观察B：本次拟建仓仓位偏离标准仓位

### 判断逻辑

```text
若 本次拟建仓仓位 ≠ 用户标准单笔仓位

则
  若 近期为亏损 且 本次仓位 > 标准仓位
  则
  解读：可能存在"亏时重仓死扛"的情绪化加仓倾向
  动作：提示纠正，建议恢复至标准仓位（PAUSE 建仓，待仓位调整后再执行）

  若 近期为盈利 且 本次仓位 < 标准仓位
  则
  解读：可能存在"赚时轻仓试水"的过度谨慎倾向
  动作：提示纠正，建议恢复至标准仓位

否则（本次仓位 = 标准仓位）
规则状态：未触发（NOT_TRIGGERED，符合等仓纪律）
```

### 解读

仓位大小若随最近的盈亏情绪波动，会导致账户整体风险敞口不稳定，尤其"亏损后加仓摊薄"极易放大单笔亏损对总资金的冲击，违背复利曲线平滑增长的目标。

### 建议动作

- 偏离标准仓位（尤其因情绪驱动）→ 暂停并提示纠正（PAUSE）
- 符合标准仓位 → 正常执行（INFORMATIONAL ONLY）

## 六、输出

### 规则状态

已触发 / 未触发 / 无法判断 / 数据不足

### 解读

判断本次拟建仓仓位是否偏离用户设定的标准仓位，以及是否存在情绪化仓位调整倾向。

### 建议动作

- 触发（偏离且疑似情绪驱动）→ 暂停，恢复标准仓位（PAUSE）
- 未触发 → 仅供参考（INFORMATIONAL ONLY）

### 证据

触发时应列出：标准仓位比例、本次拟建仓仓位比例、近期盈亏状态。

### 缺失输入

- 用户尚未设定标准单笔仓位比例（需用户提供）
- 本次拟建仓的具体仓位比例（需用户提供）

## 七、局限性

- 不评估该笔交易本身买卖时机是否正确，仅约束仓位大小的一致性
- 不能强制执行，仅能提示，最终是否遵守取决于用户
- "标准仓位"由用户自行设定，本法则不对该基准值的合理性做判断
- 不替代其他基于确定性分级的仓位策略（如法则三系列中不同确定性阶段的仓位差异），需结合使用

## 需向用户澄清的问题

- 用户的标准单笔仓位比例具体是多少？（如"1成仓"是否为固定值，还是有浮动范围）
- 是否所有标的都适用同一标准仓位，还是不同风险等级的标的有不同基准？
