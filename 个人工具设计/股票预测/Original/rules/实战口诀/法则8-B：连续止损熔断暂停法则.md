

## 来源经验

用户经验原文：

> "纪律一（等仓出击）：每笔交易仓位必须恒定（如每只票固定1成仓）。杜绝'赚时轻仓试水，亏时重仓死扛'的恶习。 纪律二（积小胜为大胜）：追求'小赚+小亏+偶有大赚'的平滑曲线，严禁出现单笔大亏。一旦连续两笔止损，立即暂停交易，调整心态而非加码赌命。 纪律三（止损铁律）：任何买入逻辑失效（破位、板块退潮）时，无论盈亏，必须无条件离场，将单笔亏损严格控制在总资金的2%以内。"

核心逻辑：本经验是关于资金/仓位管理的三条独立纪律，用户已用"纪律一/二/三"明确将其拆分为三个不同层面的规则——① 仓位分配规则（每笔交易仓位恒定）；② 连续止损后的熔断规则（连续两次止损即暂停交易）；③ 单笔止损执行规则（逻辑失效即离场，亏损上限2%）。三者触发场景（建仓时 / 连续亏损后 / 逻辑失效时）、评估对象（仓位大小 / 交易节奏 / 离场时机）、以及建议动作完全不同，按拆分原则分为**三条独立法则**。



## 一、目的

在账户连续出现止损（亏损离场）后，强制触发交易暂停机制，避免投资者在情绪失控状态下加码赌博式操作，从而保护账户资金曲线不出现单笔或连续的大幅亏损。

本法则是一条基于近期交易结果触发的"熔断"型纪律规则，不涉及具体标的的买卖判断。

## 二、适用范围

### 适用情形

- 用户在近期连续发生两笔止损（亏损离场）交易

### 不适用情形

- 用户未明确提供排除情形。
- **AI补充解释 / 限制说明**：用户原文"连续两笔止损"未明确是否要求这两笔止损之间无盈利交易穿插，此处按字面理解为"最近的两笔交易均为止损"，为对模糊表述的必要操作化处理。

## 三、所需输入

| 输入项                 | 类型    | 需要原因                |
| ------------------- | ----- | ------------------- |
| 最近两笔交易的结果（止损/止盈/其他） | 用户上下文 | 核心触发条件，判断是否"连续两笔止损" |
| 当前是否计划进行新的交易        | 用户上下文 | 判断本法则是否需要介入拦截       |

## 四、证据来源

| 输入项       | 来源                          |
| --------- | --------------------------- |
| 最近两笔交易结果  | 用户已提供 / 需用户确认（需用户记录或提供交易历史） |
| 当前是否计划新交易 | 需用户确认                       |

## 五、评估逻辑

### 观察条件

- 观察A：最近连续两笔交易均以止损（亏损）方式结束

### 判断逻辑

```text
若 最近两笔交易 = 均为止损

则
解读：账户可能已进入情绪失控或系统性判断失效状态
动作：立即暂停交易（PAUSE），进行心态调整，不得加码或立即进场

否则
规则状态：未触发（NOT_TRIGGERED）
```

### 解读

连续两笔止损往往意味着当前的市场判断逻辑与实际走势出现系统性偏差，或投资者自身心态已受到影响；此时继续交易（尤其加码）容易演变为情绪化的"赌命"行为，因此应强制暂停、冷静调整，而非继续下场。

### 建议动作

暂停交易（PAUSE）

## 六、输出

### 规则状态

已触发 / 未触发 / 无法判断 / 数据不足

### 解读

判断当前是否已连续发生两笔止损，从而是否应触发交易暂停机制。

### 建议动作

- 触发 → 暂停交易（PAUSE）
- 未触发 → 仅供参考（INFORMATIONAL ONLY）

### 证据

触发时应列出：最近两笔交易的标的、结果（止损）及大致时间。

### 缺失输入

- 用户是否有连续交易记录（需用户提供或确认最近两笔交易结果）
- "连续"是否要求两笔止损之间无其他盈利交易穿插（用户未明确定义）
- 暂停的具体时长（用户原文未定义暂停多久，仅表述为"立即暂停交易"）

## 七、局限性

- 不能判断导致连续止损的根本原因（市场系统性变化 or 个人操作失误）
- "连续两笔"的具体口径（是否允许其他交易穿插）用户未明确定义
- 暂停的具体时长或恢复交易的条件，用户未给出标准
- 不替代对具体亏损交易的复盘分析

## AI补充解释

本法则中的用户经验已相对具体明确，AI未引入额外的实质性假设，仅对"连续两笔止损"这一表述的操作化口径做了必要说明（见"不适用情形"部分）。

## 需向用户澄清的问题

- "连续两笔止损"是否要求这两笔交易之间没有其他盈利交易穿插？
- 触发暂停后，具体暂停多长时间，或需要满足什么条件才能恢复交易？
