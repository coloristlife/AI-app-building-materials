# 法则七：预期兑现与流动性溢价法则（冷洗热卖）

## 来源经验
> "利好公告日、人声鼎沸时即为主力派发日（Sell the news）。放量却不涨（滞涨），是顶部最
> 明确的语言，必须清仓。热门题材股只做短线情绪套利，不可因信仰而长期持有。"

包含两个不同层面的逻辑：①具体场景型触发规则(利好兑现+放量滞涨→清仓)；②标的类型层面的
持仓风格约束(热门题材股→只做短线)。二者触发条件、评估方式完全不同，拆分为两条独立法则
R7-A、R7-B。

---

## 法则七-A：利好兑现放量滞涨清仓（Sell the News）

**目的**：识别利好公告日/情绪高涨时"放量却不涨"（滞涨），判断为主力派发出货的最明确信号，
提示必须清仓。不预测出货后下跌的具体幅度。

**适用范围**：利好公告日或市场情绪人声鼎沸 + 放量 + 滞涨(未能相应上涨甚至下跌)。
**AI补充**：若放量当日价格仍能有效上涨(未滞涨)，不构成本法则所述信号(对核心条件的澄清)。

**必需输入**：是否存在利好公告(新闻数据)、市场情绪状态(用户上下文/新闻，需用户主观判断)、
当日/历史均量(市场数据)、当日涨跌幅(市场数据)、当前持仓(用户上下文)

**评估逻辑**：
```text
若 (利好公告 或 人声鼎沸) 且 放量 且 滞涨 且 持仓
  → 解读:主力借利好/高涨情绪派发出货 → 动作:EXIT(清仓)
否则 NOT_TRIGGERED
```

**输出**：触发→EXIT；证据=利好/情绪描述+放量程度+涨跌幅；
缺失=人声鼎沸的判定标准、放量倍数、滞涨标准、是否持仓

**局限性**：不能预测出货后跌幅/速度；人声鼎沸/滞涨缺乏数值定义，依赖舆情或主观感受；不能
区分主力出货与其他放量滞涨原因；不替代具体清仓比例及执行纪律

**AI补充解释**：本法则已相对明确，仅对"滞涨"适用边界做必要澄清
**待澄清**：人声鼎沸具体通过什么方式判断？滞涨的具体标准？清仓是否要求一次性全部卖出？

## 法则七-B：热门题材股短线情绪套利

**目的**：明确热门题材股应定位为短线情绪套利工具而非长期价值标的，避免因"信仰"长期持有
而承担题材退潮风险。这是持仓风格约束，非具体价量触发规则。

**适用范围**：标的被归类为热门题材股(因市场热点/概念炒作受资金集中追捧)。**AI补充**：若
标的同时具备扎实基本面支撑，是否仍完全排除长期持有，用户原文未做区分，此处按整体归类处理。

**必需输入**：标的是否属于热门题材股(用户上下文/新闻)、用户当前持仓意图(用户上下文)

**评估逻辑**：
```text
若 标的类型=热门题材股 → 解读:应定位为短线情绪套利工具 → 动作:AVOID(避免长期持有)
否则 NOT_APPLICABLE(本法则仅针对热门题材股)
```

**输出**：触发→AVOID长期持有；证据=判定为热门题材股的依据；
缺失=热门题材股的判定依据、用户持仓意图

**局限性**：不提供具体退出的价量信号(应结合其他法则)；热门题材股缺乏明确分类标准；不评估
标的是否同时具备基本面价值；不替代具体短线操作纪律

**AI补充解释**：若热门题材股同时基本面扎实，用户原文未明确是否仍应排除长期持有，AI按整体
归类处理，未做进一步细分

**待澄清**：热门题材股具体如何界定？短线情绪套利的持仓周期大致多久？若基本面扎实是否仍
完全适用"不可长期持有"？
