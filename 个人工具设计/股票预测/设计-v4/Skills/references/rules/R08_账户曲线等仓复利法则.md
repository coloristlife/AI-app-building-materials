# 法则八：账户曲线的"等仓复利"法则（核心命脉）

## 来源经验
> "纪律一（等仓出击）：每笔交易仓位必须恒定。杜绝'赚时轻仓试水，亏时重仓死扛'的恶习。
> 纪律二（积小胜为大胜）：追求'小赚+小亏+偶有大赚'的平滑曲线，严禁单笔大亏。连续两笔止损，
> 立即暂停交易，调整心态而非加码赌命。
> 纪律三（止损铁律）：买入逻辑失效时，无论盈亏，必须无条件离场，单笔亏损控制在总资金2%以内。"

用户已用"纪律一/二/三"明确拆分为三条独立法则：R8-A(仓位恒定)、R8-B(连续止损熔断)、
R8-C(逻辑失效离场+2%上限)。三者触发场景、评估对象、建议动作完全不同。

---

## 法则八-A：等仓出击（仓位恒定纪律）

**目的**：规范每笔交易建仓仓位恒定，杜绝情绪化仓位调整（赚时轻仓、亏时重仓），保护账户
风险结构一致性。这是建仓时的仓位约束规则，不涉及买卖时机判断。

**适用范围**：每一笔新建仓交易。**AI补充**：本法则约束"单笔标准仓位"是否恒定，不排斥
基于确定性分级使用不同仓位单位(如法则三-B/三-C)，但每个仓位单位本身应保持恒定。

**必需输入**：用户设定的标准单笔仓位比例(用户上下文)、本次拟建仓仓位(用户上下文)、
近期交易盈亏状态(用户上下文)

**评估逻辑**：
```text
若 拟建仓仓位≠标准仓位:
  若 近期亏损 且 本次仓位>标准仓位 → 解读:亏时重仓死扛倾向 → 动作:PAUSE,恢复标准仓位
  若 近期盈利 且 本次仓位<标准仓位 → 解读:赚时轻仓试水倾向 → 动作:PAUSE,恢复标准仓位
否则(仓位=标准仓位) → NOT_TRIGGERED
```

**输出**：触发→PAUSE恢复标准仓位；证据=标准仓位+本次仓位+近期盈亏；
缺失=标准仓位未设定、本次拟建仓仓位

**局限性**：不评估该笔交易买卖时机是否正确；仅能提示不能强制执行；标准仓位由用户自设，
本法则不判断其合理性；不替代基于确定性分级的仓位策略

**待澄清**：标准单笔仓位具体是多少？是否所有标的都适用同一标准仓位？

## 法则八-B：连续止损熔断暂停

**目的**：连续止损后强制暂停交易，避免情绪失控状态下加码赌博式操作，保护账户曲线。
这是基于近期交易结果触发的"熔断"型纪律规则。

**适用范围**：最近连续两笔交易均为止损。**AI补充**：用户原文未明确两笔止损间是否可穿插
其他交易，此处按字面理解为"最近两笔交易均为止损"。

**必需输入**：最近两笔交易结果(用户上下文)、当前是否计划新交易(用户上下文)

**评估逻辑**：
```text
若 最近两笔交易=均止损 → 解读:可能情绪失控/系统性判断失效 → 动作:PAUSE(暂停交易)
否则 NOT_TRIGGERED
```

**输出**：触发→PAUSE；证据=最近两笔交易标的/结果/时间；
缺失=交易记录、连续口径是否允许穿插、暂停时长

**局限性**：不能判断连续止损的根本原因；"连续两笔"口径未明确；暂停时长/恢复条件未给出；
不替代对亏损交易的复盘分析

**待澄清**：连续两笔止损是否要求无其他盈利交易穿插？暂停多长时间或满足什么条件才能恢复？

## 法则八-C：止损铁律（逻辑失效离场+2%亏损上限）

**目的**：买入逻辑失效(破位/板块退潮)时无论盈亏必须无条件离场，并将单笔亏损严格控制在
总资金2%以内，作为单笔风险敞口的底线纪律。

**适用范围**：买入逻辑已失效(价格破位或板块退潮)；或浮动亏损已达总资金2%。**AI补充**：
"无论盈亏"意味着即使当前仍盈利，逻辑失效也应离场了结，而非仅在亏损时才执行。

**必需输入**：当初买入逻辑内容(用户上下文)、当前价格是否破位(市场数据/衍生)、板块/题材
是否退潮(新闻/用户上下文)、该笔交易浮动盈亏(衍生)、用户总资金规模(用户上下文)

**评估逻辑**：
```text
若 买入逻辑已失效(破位 或 板块退潮) → 解读:依据不再成立 → 动作:EXIT(无条件离场,无论盈亏)
否则 若 浮动亏损≥总资金2% → 解读:触及风控上限 → 动作:EXIT
否则 NOT_TRIGGERED
```

**输出**：触发→EXIT；证据=买入逻辑+当前状态表现+浮亏占比；
缺失=买入逻辑内容、破位/退潮的判定标准、总资金规模及仓位占比

**局限性**：不能自动判断逻辑是否失效，依赖用户如实反馈；破位/退潮缺乏统一量化标准；2%
是用户给出的明确标准，但计算依赖总资金和仓位信息；不评估买入逻辑本身合理性；不能区分逻辑
失效与短期正常波动

**AI补充解释**：本法则已相对明确(2%为用户明确给出)，仅对"无论盈亏"的适用范围做必要强调
**待澄清**：价格破位具体指跌破什么参考位？板块退潮通过什么信号判断？总资金规模及每笔仓位
占比分别是多少？
