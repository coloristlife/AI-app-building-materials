# 法则九：逆向情绪法则（贪婪与恐惧）

## 来源经验
> "贪婪与恐惧不断碰撞，别人贪婪我恐惧，别人恐惧我贪婪。"

核心逻辑：市场整体情绪与个人应采取的操作态度呈反向关系——市场贪婪时保持谨慎，市场恐惧时
保持进取，进行反向操作。两个方向互为对称，构成同一法则的两个评估分支。

## 1. 目的
识别市场整体情绪处于极端贪婪或恐惧状态，提示采取与大众相反的操作倾向，避免群体贪婪时追高、
群体恐惧时杀跌。不预测情绪极端之后的具体走势或反转时点。

## 2. 适用范围
**适用情形**：市场(或标的)呈现明显贪婪特征；呈现明显恐惧特征。
**AI补充**：若情绪由重大基本面事件驱动且尚未出清，单纯反向操作可能面临基本面持续恶化/
向好的风险。

## 3. 必需输入
| 输入 | 类型 |
|---|---|
| 市场情绪状态 | 用户上下文/新闻 |
| 情绪极端程度参考指标(如有) | 衍生数据 |
| 当前持仓/操作意图 | 用户上下文 |

## 4. 证据来源
情绪状态→需用户确认/新闻数据；极端程度指标→衍生计算；持仓/意图→用户已提供/需用户确认

## 5. 评估逻辑
```text
若 市场情绪=明显贪婪 → 解读:大众过度乐观 → 动作:AVOID/REDUCE
否则 若 市场情绪=明显恐惧 → 解读:大众过度悲观 → 动作:BUY/SCALE IN
否则 NOT_TRIGGERED
```

## 6. 输出
- 建议动作：贪婪→AVOID/REDUCE；恐惧→BUY/SCALE IN
- 证据：判定情绪的具体依据(舆情、市场表现、指标数值)
- 缺失输入：贪婪/恐惧的量化标准或数据来源、极端程度阈值、持仓/操作意图

## 7. 局限性
- 不能预测情绪极端后反转的具体时点或幅度
- 贪婪/恐惧缺乏统一量化标准，依赖主观感受或舆情数据
- 不适用于由尚未出清的重大基本面因素驱动的极端情绪
- 不替代具体买卖点位、仓位比例及止损纪律
- 不能区分短期情绪极端与趋势性持续情绪状态

## AI补充解释
1. 若情绪由尚未出清的基本面因素驱动，反向操作可能面临风险
2. 引入"情绪极端程度参考指标"维度，但具体指标未指定
