# 法则一：逆向乖离法则（买阴卖阳）

## 来源经验
> "恐慌时（阴线）拿先手，贪婪时（阳线）给筹码……早盘急跌不割肉，尾盘拉升不追高。"

核心逻辑：超短线博弈中，情绪化的追涨杀跌是散户亏损的根源；应在市场恐慌（下跌/阴线）时
保持仓位不割肉，在市场亢奋（拉升/阳线）时不追加买入，利用"预期差"进行反向操作。

## 1. 目的
识别超短线交易中由市场情绪（恐慌/贪婪）驱动的非理性价格行为，避免在恐慌性下跌中割肉、
在亢奋性拉升中追高，控制情绪化交易带来的风险。不用于判断趋势方向或预测后续走势。

## 2. 适用范围
**适用情形**：处于超短线/日内交易场景；早盘急跌阴线（恐慌特征）；尾盘急拉阳线（贪婪特征）。
**不适用情形**：用户未明确提供排除情形。
**AI补充解释/限制说明**：若由重大基本面消息（财报、监管事件）驱动，情绪判断可能失效。

## 3. 必需输入
| 输入 | 类型 | 需要原因 |
|---|---|---|
| 当前K线颜色 | 市场数据 | 判断恐慌/贪婪阶段 |
| 当前交易时段(早盘/尾盘) | 市场数据 | 区分早盘/尾盘两种情境 |
| 价格变动幅度/速度 | 衍生数据 | 判断"急跌""拉升"程度，用户未给具体阈值 |
| 当前持仓情况 | 用户上下文 | "不割肉"前提是有持仓 |
| 是否处于超短线策略中 | 需用户确认 | 确认适用场景 |

## 4. 证据来源
| 输入 | 来源 |
|---|---|
| K线颜色 | 市场数据 |
| 交易时段 | 市场数据 |
| 急跌/拉升幅度 | 衍生计算(阈值未定义) |
| 持仓情况 | 用户已提供/需用户确认 |
| 超短线策略确认 | 需用户确认 |

## 5. 评估逻辑
```text
若 时段=早盘 且 K线=明显急跌(阴线) 且 持有仓位
则 解读:恐慌阶段 → 动作:HOLD(不割肉)

否则 若 时段=尾盘 且 K线=快速拉升(阳线)
则 解读:贪婪阶段 → 动作:AVOID(不追高)

否则 NOT_TRIGGERED
```

## 6. 输出
- **状态**：TRIGGERED/NOT_TRIGGERED/INCONCLUSIVE/INSUFFICIENT_DATA
- **建议动作**：恐慌→HOLD；贪婪→AVOID；未触发→INFORMATIONAL ONLY
- **证据**：时段、K线颜色、价格变动幅度
- **缺失输入**：急跌/拉升阈值、是否持仓、是否超短线框架

## 7. 局限性
- 不能确认恐慌性下跌会止跌反弹，也不能确认贪婪性拉升会持续上涨
- 不构成趋势方向判断，仅为情绪阶段的定性识别
- "急跌""拉升"缺乏明确数值定义，存在主观性
- 不适用于重大基本面事件驱动的行情
- 不替代仓位管理或止损纪律

## AI补充解释
1. 将"早盘急跌""尾盘拉升"识别为"阴线恐慌""阳线贪婪"两种情境的具体时间窗口
2. 补充本法则可能在重大基本面消息驱动的行情中失效
