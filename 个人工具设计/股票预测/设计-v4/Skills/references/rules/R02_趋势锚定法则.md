# 法则二：趋势锚定法则（年线定生死）

## 来源经验
> "年线（250MA）是机构长期成本线。走平向下意味着存量博弈或熊市，只做超跌反弹，不做格局；
> 年线拐头向上代表长牛确立，回踩年线是中线确定性极高的'倒车接人'点。"

核心逻辑：250日均线代表机构长期持仓成本区域，其形态决定市场处于存量博弈/熊市还是长期牛市；
不同市场状态下应采取不同策略——熊市阶段仅做短线超跌反弹，牛市确立后回踩年线是中线布局的
高确定性买点。

## 1. 目的
利用年线的形态和斜率，识别市场所处宏观阶段，决定采取"仅超跌反弹"还是"回踩买入"策略。
不预测短期价格走势，不保证回踩后必然反弹。

## 2. 适用范围
**适用情形**：年线走平/向下(存量博弈/熊市)；年线拐头向上(长牛确立)；价格回踩年线附近。
**不适用情形**：用户未明确提供。
**AI补充**：基于中长期指标，不适用于日内/超短线；上市不足250交易日数据不完整时无法评估。

## 3. 必需输入
| 输入 | 类型 | 需要原因 |
|---|---|---|
| 250日均线数值序列 | 衍生数据 | 判断年线形态 |
| 年线斜率/方向 | 衍生数据 | 核心判断依据 |
| 当前价格 | 市场数据 | 判断是否回踩 |
| 历史价格(≥250日) | 市场数据 | 计算年线所需 |
| 价格与年线偏离度 | 衍生数据 | 判断是否构成"回踩" |

## 4. 证据来源
均线数值/斜率/偏离度→衍生计算；当前价格/历史价格→市场数据

## 5. 评估逻辑
```text
若 年线=走平 或 向下 → 解读:存量博弈/熊市 → 动作:仅超跌反弹,不做格局

否则 若 年线=拐头向上
  若 价格回踩年线附近 → 解读:中线高确定性买点 → 动作:BUY/SCALE IN
  否则 → INCONCLUSIVE(未回踩)

否则 INSUFFICIENT_DATA
```

## 6. 输出
- **建议动作**：熊市→仅超跌反弹；牛市+回踩→BUY/SCALE IN；牛市未回踩→WAIT
- **证据**：年线走势、斜率方向、当前价格相对位置
- **缺失输入**：走平/拐头的斜率标准、回踩偏离度范围、历史数据是否满250日

## 7. 局限性
- 不能确认熊市何时结束/牛市何时开始
- 不保证回踩后必然反弹
- "走平""拐头向上""回踩"缺乏明确数值定义
- 不适用于上市不足250交易日的标的
- 不替代仓位管理、止损纪律
- 无法用于日内/超短线决策

## AI补充解释
1. 补充说明标的历史数据不足250日时年线无法计算，法则不可评估
2. 将"回踩年线"操作化为价格与年线的偏离度，但阈值未给出
