# 法则十：本金优先保护法则（宁失浮盈，不损本金）

## 来源经验
> "可以输掉浮盈，但必须保住本金，而多数人对浮盈和本金的认识还不够。本金输没了，就等于白忙
> 活一场，因为本金的积累是需要时间的。"

核心逻辑：浮动盈利可以接受损失，但本金必须被严格保护。当"可能损失本金"与"仅损失部分浮盈"
需要抉择时，应始终选择保住本金。

## 1. 目的
明确保护本金的重要性高于保护浮动盈利，提示浮盈回吐且逼近本金时应优先保护本金(减仓/止损/
离场)，而非因不舍浮盈已损失而继续承担本金风险。这是一条贯穿交易全程的风险优先级原则。

## 2. 适用范围
**适用情形**：该笔交易曾有浮盈，后价格回落，浮盈正在回吐且逼近或触及本金线。
**AI补充**：本法则针对"已有浮盈且正在回吐"的情形；若从建仓起持续亏损、从未有浮盈，应直接
适用一般止损纪律(如法则八-C)，而非本法则。

## 3. 必需输入
| 输入 | 类型 |
|---|---|
| 买入成本(本金) | 用户已提供 |
| 曾达到的最高浮盈水平 | 用户已提供/需用户确认 |
| 当前价格/浮动盈亏 | 市场数据 |
| 当前价格距本金线的距离 | 衍生计算 |

## 5. 评估逻辑
```text
若 曾有浮盈 且 浮盈正在回吐 且 价格逼近/触及本金线
  → 解读:本金面临被侵蚀风险 → 动作:EXIT/REDUCE(接受浮盈损失,保住本金)

否则 若 浮盈回吐但价格仍明显高于本金线 → INCONCLUSIVE(暂不构成强制离场条件)

否则 NOT_TRIGGERED
```

## 6. 输出
- 建议动作：本金面临风险→EXIT/REDUCE；本金尚安全→INCONCLUSIVE，可继续观察
- 证据：买入成本、曾达到的最高浮盈、当前价格及距本金线距离
- 缺失输入：逼近本金的距离阈值、买入成本及历史最高浮盈

## 7. 局限性
- 不能预测价格是否会在触及本金线前企稳反弹
- "逼近本金"缺乏明确数值定义
- 不涉及从未产生浮盈、从建仓起即持续亏损的情形(应适用法则八-C)
- 不替代具体止损点位设置
- 可能存在过早离场的风险

## AI补充解释
1. 界定适用边界为"曾有浮盈且正在回吐并逼近本金"，区别于从未有浮盈的一般止损情形
2. "逼近本金"作为需衍生计算的距离指标，但具体触发阈值未给出
