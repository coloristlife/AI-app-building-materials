# 法则十一：卖出后情绪稳定法则（不因卖飞而追悔冲动）

## 来源经验
> "股票解套了或者止盈了，往往都会后悔卖飞了，稳住心态才是关键。"

核心逻辑：解套或止盈离场后价格继续上涨，投资者常产生"卖飞了"的后悔情绪；应保持心态稳定，
不因这种情绪做出冲动的追加买入或非理性操作。这是关于卖出后情绪管理的行为纪律。

## 1. 目的
识别投资者卖出(解套/止盈)后因价格继续上涨产生后悔情绪的情形，帮助保持心态稳定，避免因
后悔驱动做出冲动追高买回或打乱既定交易计划的行为。不判断该笔卖出决策本身是否正确。

## 2. 适用范围
**适用情形**：此前已卖出某标的(解套或止盈离场)，卖出后价格继续上涨。
**AI补充**：若卖出是因止损后价格反而上涨，情绪性质和应对方式可能不同(更偏向"错过反弹"的
懊恼而非"卖飞盈利"的后悔)，用户原文未涵盖此情形。

## 3. 必需输入
| 输入 | 类型 |
|---|---|
| 该笔交易卖出原因(解套/止盈) | 用户上下文 |
| 卖出后价格走势 | 市场数据 |
| 用户当前情绪状态(是否后悔/冲动追高倾向) | 需用户确认 |

## 5. 评估逻辑
```text
若 卖出性质=解套或止盈 且 卖出后价格继续上涨 且 用户表现出后悔/冲动追高倾向
  → 解读:常见的"卖飞"后悔心理,需警惕驱动非理性追高 → 动作:PAUSE(稳住心态,暂缓追高买回)
否则 NOT_TRIGGERED
```

## 6. 输出
- 建议动作：稳住心态，暂缓冲动追高买回；若确实想重新买入，应基于独立当下逻辑重新评估
- 证据：卖出性质、卖出后涨幅、用户表达的情绪或追高意图
- 缺失输入：用户是否确实存在后悔情绪(需主动表达)

## 7. 局限性
- 不判断该笔卖出决策本身是否正确
- 不预测价格后续是否继续上涨
- 无法独立识别用户情绪，依赖主动表达
- 不涵盖止损卖出后价格上涨的情形
- 不提供是否应重新买入的具体决策依据

## AI补充解释
1. 界定适用边界为"解套/止盈"后的卖飞后悔，不涵盖止损情形
2. 补充"应基于独立当下逻辑评估"作为更具体的行为指引
