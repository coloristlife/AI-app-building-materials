# 法则十二：位置反向评判法则（高位不讲故事，低位不看业绩）

## 来源经验
> "高位不讲故事，低位不看业绩，所以两者是反过来换位思考的。"

核心逻辑：股价所处位置决定应重点警惕/弱化的评判维度——高位时不应轻信"故事"(题材/概念叙事)，
因为更可能是拉高出货说辞；低位时不应仅因业绩不佳完全否定标的，因为可能已被市场price in。
两者构成对称的"换位"关系，不拆分为独立法则。

## 1. 目的
提示应根据股价位置(高位/低位)动态调整评判依据——高位对故事保持警惕，低位不因业绩不佳简单
否定标的，避免在高位被故事迷惑站岗、或在低位因业绩表面难看错失机会。

## 2. 适用范围
**适用情形**：高位+存在故事叙事；低位+业绩表现不佳。
**AI补充**：本法则强调降低某维度依赖权重，而非完全忽视——高位不代表故事必然虚假，低位不
代表业绩完全不重要，仅为权重调整。

## 3. 必需输入
| 输入 | 类型 |
|---|---|
| 当前价格所处位置 | 衍生数据 |
| 是否存在故事/题材叙事 | 新闻/用户上下文 |
| 当前业绩表现 | 新闻/市场数据 |

## 5. 评估逻辑
```text
若 高位 且 存在故事叙事 → 解读:故事更可能是出货说辞 → 动作:AVOID(警惕,弱化故事权重)
否则 若 低位 且 业绩不佳 → 解读:可能已被price in → 动作:INFORMATIONAL(弱化业绩权重)
否则 NOT_TRIGGERED
```

## 6. 输出
- 建议动作：高位+故事→AVOID仅凭故事追高；低位+业绩差→弱化业绩权重，综合评估
- 证据：价格位置判断依据、是否存在故事叙事或具体业绩数据
- 缺失输入：高位/低位判定标准、讲故事识别标准、业绩不佳量化标准

## 7. 局限性
- 不判断故事是否终将兑现，也不判断业绩不佳是否只是暂时现象
- 高位/低位/讲故事/业绩不佳缺乏明确数值定义
- 不代表完全否定故事真实性或业绩重要性，仅为权重调整
- 不提供具体买卖点位或仓位建议
- 不替代其他基于量价、消息面的具体法则

## AI补充解释
补充说明本法则表达的是"降低权重"而非"完全否定"，避免过度绝对化理解
