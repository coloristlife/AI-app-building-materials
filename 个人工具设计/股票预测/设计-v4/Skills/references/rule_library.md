# 投资法则库 —— 参考数据

本文件是 investment-rule-router 技能的唯一事实来源，包含：

1. 情境标签词表
2. 法则索引表（用于匹配的触发标签）
3. 标准化输入字典（去重后的必需输入字段）
4. 冲突矩阵（已知的、建议动作可能相互矛盾的法则对）
5. 各法则的精简评估逻辑（紧凑版 IF/THEN、状态、动作、局限性）
6. 规则提炼原始说明（用于向本库新增法则）

法则编号沿用最初编写时的顺序。带字母后缀（A/B/C）的子法则，表示某条用户原始经验因为
包含独立的触发条件和/或相反的建议动作，被拆分成了多条独立法则。

**关于完整法则原文**：本文件第五节给出的是每条法则的精简版评估逻辑，用于日常路由匹配和
快速评估，刻意省略了完整的七段式契约细节（如完整的"适用范围"说明、每项必需输入的详细理由、
完整的 AI 补充解释与待澄清问题列表），以控制加载到上下文中的体积。每条法则的**完整原文**
保存在 `references/rules/` 目录下的独立文件中，按需加载：
- 当用户明确要求查看某条法则的完整依据、局限性细节，或要求修改/复核某条法则时，再去读取
  对应的完整文件，不要在日常路由/评估时预先加载它们。

## 一、情境标签词表

| 维度                   | 取值                                                  |
| -------------------- | --------------------------------------------------- |
| price_position（价格位置） | 高位 / 低位 / 中位 / 未知                                   |
| volume（成交量）          | 放量 / 缩量 / 平量                                        |
| price_speed（价格速度）    | 急跌 / 缓跌 / 急涨 / 平稳                                   |
| pattern（形态）          | 横盘(前) / 三连阴 / 十字星×3 / 新低 / 新高 / 破位 / 回踩不破 / 冲高 / 滞涨 |
| timing（时段）           | 早盘 / 尾盘 / 盘中                                        |
| trend_stage（趋势阶段）    | 下跌初期 / 下跌途中 / 上涨途中 / 未知                             |
| sentiment（情绪）        | 恐慌 / 贪婪 / 人声鼎沸 / 中性                                 |
| news（消息面）            | 利好公告 / 利空 / 无消息                                     |
| ma250（年线）            | 走平 / 向下 / 拐头向上 / 未知                                 |
| stock_type（标的类型）     | 热门题材股 / 非题材股 / 未知                                   |
| account_state（账户状态）  | 已止损 / 连续两笔止损 / 有浮盈 / 浮盈回吐 / 已解套 / 已止盈 / 新建仓 / 无仓位   |

标签提取应尽量放开——用户的一句话通常会同时命中 3~5 个维度。未涉及的维度保持"未知/空"，
不要强行贴上并未真正暗示的标签。

## 四、冲突矩阵

| 法则A | 法则B | 冲突性质 | 默认处理方式 |
|---|---|---|---|
| R3-B（低位缩量试仓） | R6-B（放量急跌低吸） | 同为低位/下跌场景，但一个要求缩量、一个要求放量，二者互斥，需先确认量能方向 | 以实际 volume_state 为准，二者不会同时"已触发"；若用户描述模糊，先追问 |
| R5-A（三连阴禁止抄底） | R3-B / R6-B（试仓/低吸） | 阶段判断不同（下跌初期 vs 低位/恐慌尾声），建议动作相反 | 需 trend_stage 澄清；未澄清前不给出行动指令，仅并列展示两种可能 |
| R2（熊市只做超跌反弹） | R4-B（低位破位低吸/黄金坑） | 熊市格局下的破位，到底是继续探底还是黄金坑，仓位规模建议不同 | 结合 ma250_trend：若走平/向下，R2的"仅做超跌反弹、不做格局"限制会压低 R4-B 的建议仓位上限 |
| R3-A（高位放量下跌减仓） | R6-B（放量急跌低吸） | 高位放量急跌同时满足两者表面条件，但性质不同（派发出货 vs 恐慌抛售） | 以 price_position 为主要区分依据：高位→倾向 R3-A；非高位的急跌→倾向 R6-B |
| 任意信号类法则（R1,R2,R3,R4,R5,R6,R7,R9,R12） | R8-B / R8-C（账户纪律类） | 纪律类法则的性质是"一票否决" | **默认账户纪律类法则优先**：先提示暂停/离场/控制仓位，再把信号类法则的结论作为背景信息呈现 |

## 五、各法则精简评估逻辑

格式：触发条件 → 状态/动作 → 需始终带入最终输出的关键局限性。

**R1 逆向乖离法则（买阴卖阳）**
若 早盘+急跌 → 解读:恐慌 → 动作: HOLD(不割肉)
若 尾盘+急拉 → 解读:贪婪 → 动作: AVOID(不追高)
局限性：不判断趋势方向，仅识别情绪化定价窗口；若由重大基本面消息驱动可能失效。

**R2 趋势锚定法则（年线定生死）**
若 年线=走平/向下 → 动作: 仅超跌反弹，不做格局
若 年线=拐头向上 且 次日回踩不破 → 动作: BUY/SCALE IN(中线)
若 年线=拐头向上 但未回踩 → 动作: WAIT
局限性：不保证回踩后必然反弹；不足250日数据无法计算。

**R3-A 高位放量下跌减仓**
若 高位+放量+下跌+持仓 → 动作: REDUCE
局限性：不预测跌幅；可能是情绪性抛售而非机构出逃。

**R3-B 低位缩量新低试仓**
若 低位+缩量+新低 → 动作: SCALE IN(左侧小仓位)
局限性：不确认底部；需排除流动性枯竭型缩量。

**R3-C 增量回升右侧确认重仓**
若 放量上涨(前)+次日回踩不破 → 动作: BUY/SCALE IN(较大仓位)
若 回踩破位 → 动作: WAIT
局限性：不保证趋势延续；在特定阶段可能与R3-A冲突。

**R4-A 高位横盘冲高止盈（多头陷阱）**
若 高位+横盘(前)+冲高 → 动作: EXIT(止盈)
局限性：未结合成交量无法完全区分真突破/假突破。

**R4-B 低位横盘破低低吸（空头陷阱）**
若 低位+横盘(前)+新低 → 动作: SCALE IN(分批)
局限性：不保证反弹；可能与R2的熊市判断冲突。

**R5-A 下跌初期三连阴禁止抄底**
若 下跌初期+三连阴 → 动作: AVOID(严禁抄底)
局限性：“下跌初期”的判定标准依赖用户主观确认。

**R5-B 下跌途中三颗星中继观望**
若 下跌途中+十字星×3 → 动作: WAIT(空仓)
局限性：不确认何时终结；可能与右侧确认类法则冲突。

**R6-A 缩量缓跌弱弹性做T**
若 缓跌+缩量 → 动作: 仅做T
局限性：不预测下跌何时结束；牛熊背景不同，含义可能不同。

**R6-B 放量急跌强弹性低吸**
若 急跌/加速+放量(恐慌盘) → 动作: BUY/SCALE IN(敢于低吸)
局限性：若由重大基本面利空驱动，弹性逻辑可能不适用；可能与R5-A冲突。

**R7-A 利好兑现放量滞涨清仓**
若 (利好公告 或 人声鼎沸)+放量+滞涨+持仓 → 动作: EXIT(清仓)
局限性：“人声鼎沸”难以独立量化判断。

**R7-B 热门题材股短线情绪套利**
若 标的类型=热门题材股 → 动作: AVOID(避免长期持有)，仅做短线
局限性：不评估基本面价值；分类标准依赖用户/舆情判断。

**R8-A 等仓出击**
若 拟建仓仓位 ≠ 标准仓位(尤其亏损后加仓/盈利后减仓) → 动作: PAUSE，纠正仓位
局限性：仅能提示，不能强制执行。

**R8-B 连续止损熔断**
若 最近两笔交易均为止损 → 动作: PAUSE(暂停交易)
局限性：“连续”的具体口径及暂停时长，用户未定义。

**R8-C 止损铁律**
若 逻辑失效(破位/退潮) 或 亏损≥总资金2% → 动作: EXIT(无条件离场)
局限性：高度依赖用户对原始买入逻辑的如实反馈。

**R9 贪婪恐惧法则（逆向情绪）**
若 市场情绪=明显贪婪 → 动作: AVOID/REDUCE
若 市场情绪=明显恐惧 → 动作: BUY/SCALE IN
局限性：情绪判断难以独立量化，依赖用户/舆情。

**R10 本金优先保护法则**
若 曾有浮盈+浮盈回吐+价格逼近本金线 → 动作: EXIT/REDUCE(保住本金)
局限性：“逼近本金”的阈值未定义；不涉及从未产生浮盈的情形(该情形走R8-C)。

**R11 卖出后情绪稳定法则**
若 卖出原因∈{解套,止盈}+卖出后价格继续上涨+用户表现出后悔/冲动倾向 → 动作: PAUSE(稳住心态，暂缓追高)
局限性：无法独立识别用户情绪，需用户主动表达。

**R12 位置反向评判法则**
若 高位+存在故事叙事 → 动作: AVOID(警惕故事，弱化其权重)
若 低位+业绩不佳 → 动作: INFORMATIONAL(弱化业绩权重，综合判断)
局限性：不代表完全否定故事/业绩的价值，仅为权重上的调整。

**R13 显而易见法则**（不参与自动路由，仅按需手动调用）
无 IF/THEN 结构；仅作为复盘提示语使用："这个机会是否因为太简单、太常见而被市场（或你自己）低估了？"

## 六、规则提炼原始说明（用于新增法则）

当用户提供一段全新的个人经验、希望将其加入本法则库时，应遵循原始的七段式法则契约
（目的 / 适用范围 / 必需输入 / 证据来源 / 评估逻辑 / 输出 / 局限性），忠实保留用户的
原始含义，对任何AI补充解释均需明确标注，并且——只要原始经验中包含独立的触发条件和/或
相反的建议动作，就应拆分为多条子法则（如上文第3、4、5、6、7、8条法则的处理方式）。
完成完整法则的撰写后，还需将精简条目补充进：

- 第二节（法则索引表）—— 触发标签
- 第三节（标准化输入字典）—— 任何新增字段编号；如某概念已存在对应字段，应合并复用，
  而不是用不同名称重新创建一个（例如不要为"价格位置"这一概念再新建一个字段）
- 第五节（评估逻辑）—— 紧凑版 IF/THEN 表述
- 第四节（冲突矩阵）—— 检查该新法则的建议动作，是否与任何标签有重叠的"已触发"现有法则
  相矛盾，如有则记录在案
