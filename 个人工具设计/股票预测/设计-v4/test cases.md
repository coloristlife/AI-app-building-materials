**类别一：单条法则命中（验证基本路由）**

1. "尾盘突然拉了个大阳线，是不是该追一把？" → 预期只命中 R1（逆向乖离），建议不追高
    
2. "这票热度很高，是当下最火的题材，我准备长期拿着等它变成下一个大牛股" → 预期只命中 R7-B（热门题材股短线套利），提示不宜长期持有
    

**类别二：多条法则同时命中（核心测试点，验证合并提问）**

3. "这只票之前在低位横盘了差不多两周，今天放量创了新低，我手里还有仓位，而且这已经是我最近第二笔可能要止损的交易了" → 预期同时命中 R4-B（低位横盘破低/空头陷阱）+ R3-B候选但因是"放量"而非"缩量"应被排除或提示矛盾 + R8-B（连续止损熔断） → 应该合并问：是否持仓/仓位比例、最近两笔交易是否都是止损，而不是分开问
    
4. "早盘这票急跌了，我手上还有仓位，年线也是走平的，最近资金一直在存量博弈" → 预期命中 R1（早盘恐慌不割肉）+ R2（年线走平只做超跌反弹不做格局） → 应合并问：是否持仓、当前仓位比例
    
5. "刚才利好公告发出来了，大家都在讨论这只票，成交量放得很大，但价格就是不怎么涨" → 预期命中 R7-A（放量滞涨清仓），可能同时触发 R9（人声鼎沸=贪婪情绪） → 应合并问：是否持仓
    

**类别三：冲突场景（验证优先级和冲突提示）**

6. "低位缩量创了新低，杀跌动能看起来衰竭了，但我最近连续两笔都止损了" → 预期命中 R3-B（可以试仓）+ R8-B（应该暂停交易）→ 应明确提示纪律类法则优先，建议先暂停而非试仓
    
7. "这票下跌初期连续三根阴线，但今天成交量放得特别大，跌得也特别急，感觉像是恐慌盘在涌出" → 预期命中 R5-A（下跌初期三连阴禁止抄底）+ R6-B（放量急跌低吸）→ 两者建议相反(禁止抄底 vs 敢于低吸)，应并列展示、给出区分条件让用户自己判断当前更接近哪种阶段
    

**类别四：零匹配/信息不足**

8. "这只股票能买吗？" → 预期不强行匹配任何法则，直接反问需要更具体的情境描述
    
9. "我看这个行业未来空间很大，机会是不是就藏在大家都没注意的地方？" → 预期识别为 R13（显而易见法则），但因为是元认知/复盘性质而非交易信号，应说明这条不参与自动触发判断，只做思路提示
