# 3. 最重要的文件：`app/workflow.py`

这是整个系统的**稳定骨架**。

它实际上就是我们之前确定的十步：

```text
01 Understand
02 Contextualize
03 Retrieve Knowledge
04 Gather Evidence
05 Analyze
06 Challenge
07 Decide
08 Act
09 Monitor
10 Learn
```

第一版代码：

```python
class InvestmentWorkflow:

    def run(self, user_request):

        # 01
        task = self.o.understand(user_request)

        # 02
        context = self.o.contextualize(task)

        # 03
        knowledge = self.o.retrieve_knowledge(
            task,
            context
        )

        # 04
        evidence = self.o.gather_evidence(
            task,
            context,
            knowledge
        )

        # 03 <-> 04 micro loop
        for _ in range(2):

            missing = self.o.find_missing_evidence(
                task,
                context,
                knowledge,
                evidence
            )

            if not missing:
                break

            evidence = self.o.gather_more_evidence(
                task,
                context,
                knowledge,
                evidence,
                missing
            )

            knowledge = self.o.refine_knowledge(
                task,
                context,
                knowledge,
                evidence
            )

        # 05
        analysis = self.o.analyze(
            task,
            context,
            knowledge,
            evidence
        )

        # 06
        challenge = self.o.challenge(
            task,
            context,
            knowledge,
            evidence,
            analysis
        )

        # 07
        decision = self.o.decide(
            task,
            context,
            knowledge,
            evidence,
            analysis,
            challenge
        )

        # Persistence
        case = DecisionCase(...)

        self.o.persist_case(case)

        return case
```

这里有一个非常关键的设计：

> **Workflow 完全不知道 R001、R002、R003 是什么。**

因此以后你再增加：

```text
R011
R012
R013
...
R500
```

`workflow.py` 都不用修改。

# 8. 这解决了你之前一直担心的问题

你之前问：

> “如果 Skill 里面只有 Reference，大模型不是不知道 Reference 具体是什么吗？”

现在架构是：

```text
Skill
 ↓
告诉 Agent：
“我要调用 Knowledge Resolver”
 ↓
Knowledge Resolver
 ↓
找到具体 Knowledge Object
 ↓
Context Builder
 ↓
把真正的 Knowledge 内容
加入当前 LLM Context
 ↓
LLM
```

所以不是：

```text
Skill
 ↓
Reference
 ↓
LLM自己猜
```

而是：

```text
Skill
 ↓
Resolver
 ↓
Actual Knowledge
 ↓
LLM
```

这才是正确的实现。

# 19. 所以第一版不要做成“炒股 App”

我建议你的 V1 定位为：

> **Personal Investment Decision Engine**

而不是：

> AI 自动炒股。

第一阶段重点验证四件事情：

### ① 我的经验能不能被正确结构化

```text
Experience
→ Knowledge Object
```

### ② Agent 能不能找到正确经验

```text
Context
→ Knowledge Resolver
```

### ③ Agent 能不能结合现实证据判断

```text
Knowledge
+
Evidence
→ Analysis
```

### ④ 每次决策能不能完整保存

```text
Decision
→ Case
→ History
→ Review
```

只要这四件事跑通，后面接真实行情、真实 LLM、DojoAgents、MCP、甚至交易 API 都是增量工作。
